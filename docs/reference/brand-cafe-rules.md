## 1. 브랜드별 사진 규칙 표

### 1-1. 공통 해석 규칙 (`images.py`)

| 항목 | 규칙 |
|---|---|
| 플레이스홀더 문법 | `PLACEHOLDER_PATTERN = \{([^{}\r\n]+)\}` — 한 줄 안, 중괄호 안 개행 불가 |
| 사진 개수 | **본문에 등장하는 `{...}` 개수 = 첨부 사진 개수**. 고정 개수 없음 |
| 사진 위치 | `{...}`가 있던 그 줄에 이미지 컴포넌트를 삽입. 한 줄에 여러 개면 순서대로 연속 삽입 (`_content_json`) |
| 문단 보존 | `{...}`만 있던 줄은 **빈 문단으로 남겨** 이미지 앞뒤 간격을 유지 |
| 토큰 → 폴더 | 기본은 **토큰 문자열 = 브랜드 폴더 하위 폴더명**. 비교는 공백제거 + casefold |
| 선택 방식 | 해당 폴더의 파일 목록을 `random.SystemRandom().sample()`로 섞어 **다운로드 성공한 첫 장** 사용 |
| 제외 | `excluded_file_ids` 집합에 든 Drive 파일 ID는 후보에서 제외. 한 실행 안에서 고른 사진은 `job.prepared_images`에 고정되어 재시도해도 바뀌지 않음 |
| 이미지 끄기 | 시트 I열 `이미지 없음` 값이 `y`(대소문자 무시)이면 `image_disabled=True` → **사진 0장**, 중괄호만 제거 |
| 폴더/파일 미발견 | 해당 `{...}` 하나만 건너뛰고 경고 로그. 단 제휴/자사 발행에서는 **`{...}`가 남아 있는데 사진이 0장이면 발행 중단** (`affiliate_api._prepare_revision_content`) |
| 최종 본문 | `strip_placeholders()`로 모든 `{...}` 제거. 등록 후 본문에 `{`가 남아 있으면 검증 실패 |
| 일상 글 | **사진 없음**. `daily_posts.load_daily_posts`는 이미지 경로를 다루지 않고, Excel 일상 글은 `image_disabled=True` 고정 |
| 한 줄 테스트 | `image_disabled=True` 고정 |
| 사진 전처리 | PNG/WebP는 흰 배경 JPG로 변환 후 포토워셔(EXIF/해시 변경) 적용 (`photo_washer.py`, HANDOFF 기준) |

코드 근거 (`images.resolve`):


`keyword_placeholder`는 `marker == "키워드"` **또는** `공백제거(marker) == 공백제거(A열 키워드)`.
즉 `{다이어트 유산균}`처럼 키워드를 그대로 쓴 토큰도 `키워드` 폴더로 간다 (팥순이·장으뜸·뉴더미스만).

### 2-1. 원고(본문 셀) 문법 — 전 브랜드 공통 (`content.parse_article`)

```text
제목 :
<제목 줄들>

본문 :
<본문 줄들, {폴더명} 사진 표시 포함>

댓글1 : ...
대댓글1 : ...
댓글2 : ...
대댓글2 : ...
대대댓글2 : ...
대대대댓글2 : ...
댓글3 : ...
대댓글3 : ...
댓글4 : ...
대댓글4 : ...
댓글5 : ...
대댓글5 : ...
```

- 라벨은 `#` 머리말, `*`/`_`/`` ` `` 1~3개 장식, `제목`/`본문` 단독 헤딩 형태도 허용.
- `--- ` 구분선, `#### … 댓글 세트` 헤딩은 무시.
- 깊이는 `대`의 개수. 번호 생략 시 루트는 자동 증가, 하위는 부모 번호를 상속.
- 제목·본문이 비면 `ContentFormatError`. 제휴 시트는 이 오류가 나면 **전체 배치 중단**,
  즉시발행 브랜드 시트는 **그 행만 실패**, 정보성/일상 시트는 **그 행만 조용히 무시**.
- **태그**: `tags = [공백 제거한 A열 키워드]` — 정확히 1개. 시트 태그 열 없음. 키워드가 비면 오류.
  (레거시 범용 `sheet.load_jobs`에는 `태그` 열 별칭과 `[,#\n]` 분리·최대 10개 규칙이 있으나
  브랜드/제휴 경로에서는 쓰이지 않는다.)
- **제목**: 원고의 `제목 :` 값을 그대로 사용. 자동 가공 없음.
- **본문 줄바꿈/문장부호**: 브랜드 시트는 **원문 그대로**. 자동 정리(`format_daily_body`)는
  정보성 시트와 Excel 일상 글에만 적용.

### 3-1. 댓글 열 구조

- **제휴/브랜드/정보성 시트에는 `댓글N` 전용 열이 없다.** 댓글은 B열 `본문` 안에
  `댓글N :` / `대댓글N :` / `대대댓글2 :` / `대대대댓글2 :` 계층 텍스트로 들어간다.
- 레거시 범용 로더 `sheet.load_jobs`만 `댓글`/`댓글1`/`comment N` 형태의 **별도 열**을
  정규식 `(댓글|comment)\s*\d*`로 수집한다. 현재 운영 시트 중 이 형식을 쓰는 것은 없다.

### 3-2. 브랜드 시트

**브랜드별 Google Sheet ID는 코드·config 어디에도 저장되어 있지 않다.** 레거시에서는 GUI에
사용자가 URL을 붙여넣고, 프로그램이 그 URL의 `og:title` 마지막 괄호에서 브랜드명을 읽는다
(`images.load_sheet_brand`). `config/sources.yaml`의 `brand_sheets: {}`도 비어 있다.
→ **우아덤·코숨핏·뉴더미스·장으뜸·팥순이 시트는 이번 조사로 확인할 수 없었다.**
브랜드 시트의 열 구조는 정보성 시트와 동일한 A~J 10열이다(HANDOFF 모드 A 기준).

### 3-3. 탭 열거에 대한 참고

`https://docs.google.com/spreadsheets/d/<ID>/edit` HTML에서 `"sheetId"`/name 쌍을 뽑으려 했으나,
로그인 없이 받는 HTML에는 시트 목록 부트스트랩 데이터가 포함되지 않았다(매칭된 것은
`yy. M. d` 같은 숫자 서식 정의였고, 그 gid로 CSV를 받으면 기본 탭이 반환됨).
**탭 전수 열거는 로그인 없이는 불가.** 위 표의 gid는 config에 명시된 값 + `gid=0`만 검증한 것이다.

### 불일치

| 종류 | 항목 | 설명 |
|---|---|---|
| 폴더만 있고 토큰 미확인 | 코숨핏 하위 18개 폴더 전부, 뉴더미스 하위 5개(키워드 제외) | 브랜드 시트를 못 읽어 실제 사용 토큰을 대조하지 못함. 폴더명 == 토큰이라는 코드 규칙상 그대로 쓰면 된다 |
| 빈 폴더 | `코숨핏/키워드` (0개) | `{키워드}` 토큰이 쓰이면 사진이 생략되고, 다른 사진이 하나도 없으면 **발행 중단**된다. 채우거나 토큰을 쓰지 않아야 함 |
| 브랜드 폴더 없음 | `우아덤` 루트 직접 파일 0개, 하위는 `키워드` 하나뿐 | 우아덤은 `{키워드}` 외 토큰을 쓸 수 없음 |
| 브랜드 외 폴더 | `기관총_선택이미지` (하위 3개 타임스탬프 폴더, 총 28장) | 브랜드 폴더 아님. 다른 도구(기관총) 산출물로 보임 — 토큰 매핑 대상 아님 |
| 브랜드 외 폴더 | `photowasher2.1` (exe 1 + txt 2) | 포토워셔 실행파일. 이미지 폴더 아님 |
| 루트 직접 파일 | 뉴더미스 4장, 코숨핏 37장, 장으뜸 30장 | `resolve()`는 **브랜드 폴더의 하위 폴더만** 조회하므로 이 파일들은 절대 선택되지 않는다 |
| 경로 중복 | `inbox\image\image\…` | `image`가 두 번 겹침. 새 설정에서는 루트를 `warehouse/inbox/image/image`로 잡거나 한 겹 정리 필요 |

## 6. 읽지 못한 것 / 확인 필요

1. **브랜드별 Google Sheet (우아덤·코숨핏·뉴더미스·장으뜸·팥순이)** — ID가 코드/config
   어디에도 없어 조회 불가. 실제 사용 중인 `{...}` 토큰 분포, 브랜드별 카페·게시판 값,
   말머리 값, 원고유형(질문형/후기형) 비율은 **미확인**.
2. **`각색 전체` 시트 `1WlNgw9Jzr7dWYAabqVB3yn220--uucVb`** — HTTP 404. `config/sources.yaml`
   에서 제거하거나 새 ID로 교체 필요. `config/sources.json`에는 `20260903_…`,
   `sources.yaml`에는 `각색 전체`로 이름만 다르게 남아 있다.
3. **탭 전수 열거** — 로그인 없는 HTML에 시트 목록이 없어 불가. config에 적힌 gid + gid=0만 검증.
4. **랜덤일상 시트에 양평맘 일상 글 0건** — 양평맘/쌍둥이맘 모여라 제휴 작업은 현재 데이터로는
   `일상 글이 부족합니다` 오류가 난다.
5. **정보성 시트가 완료 아카이브 상태** (키워드·본문 열이 비어 있음) — 신규 작업에 그대로 쓸 수 없다.
6. **로컬 인박스와 Drive 루트의 동기화 여부 미확인.** 레거시는 Drive만 읽는다.
