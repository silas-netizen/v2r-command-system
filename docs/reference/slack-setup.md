# 슬랙 연결 설정 (비개발자용)

이 문서대로만 따라 하면 됩니다. 순서를 지켜 주세요.

## 왜 필요한가

슬랙에 연결하면 실행기가 보고 문구뿐 아니라 **파일(HTML·MD 원고, 현황판, 목록)**
도 슬랙 채널로 직접 보내줍니다. 텔레그램과 같은 역할을, 슬랙에서도 하게 됩니다.

## 1. 슬랙 앱 만들기

1. 브라우저에서 https://api.slack.com/apps 접속 → 슬랙 로그인.
2. "Create New App" 클릭 → "From scratch" 선택.
3. 앱 이름(예: `V2R 봇`)과 워크스페이스를 고르고 "Create App".

## 2. 봇 권한(Scopes) 설정

왼쪽 메뉴에서 **OAuth & Permissions** 클릭 → 아래로 스크롤해
**Bot Token Scopes** 항목을 찾습니다. "Add an OAuth Scope"를 눌러
아래 6개를 하나씩 추가하세요.

| 권한(Scope) | 용도 |
|---|---|
| `chat:write` | 메시지 보내기 |
| `files:write` | 파일(HTML·MD·사진) 올리기 |
| `channels:read` | 공개 채널 정보 확인 |
| `channels:history` | 공개 채널 메시지(명령) 읽기 |
| `groups:read` | 비공개 채널(그룹) 정보 확인 |
| `groups:history` | 비공개 채널(그룹) 메시지(명령) 읽기 |

> 비공개 채널(그룹)에서도 명령을 받으려면 `groups:read`·`groups:history`
> 두 개가 **꼭** 있어야 합니다. 공개 채널만 쓸 거면 이 둘은 생략해도 됩니다.

화면 예시: 이 페이지 왼쪽 메뉴 **OAuth & Permissions** → 페이지 중간
"Scopes" 박스 안 "Bot Token Scopes" 항목입니다.

## 3. 워크스페이스에 설치

같은 **OAuth & Permissions** 페이지 맨 위로 올라가서
"Install to Workspace" (또는 "Install App") 버튼 클릭 → "허용" 클릭.

## 4. 봇 토큰 복사

설치가 끝나면 같은 페이지 위쪽에 **Bot User OAuth Token**이 보입니다.
`xoxb-`로 시작하는 긴 문자열입니다. "Copy" 버튼으로 복사해 두세요.
(이 토큰은 비밀번호와 같으니 다른 사람에게 보여주지 마세요.)

## 5. 채널에 봇 초대

보고를 받고 싶은 슬랙 채널(공개든 비공개든)에 들어가서:

1. 채널 이름 클릭 → "통합" 또는 "Integrations" 탭 → "앱 추가"
   (또는 채팅창에 `/invite @봇이름` 입력 후 Enter)
2. 방금 만든 봇을 선택해 초대.

## 6. 채널 ID 확인

1. 슬랙 채널 이름을 클릭해 채널 상세정보를 엽니다.
2. 맨 아래로 스크롤하면 "채널 ID"가 보입니다(`C`로 시작하면 공개,
   `G`로 시작하면 비공개 채널입니다). 복사해 두세요.
3. 보고를 받을 채널이 여러 개면 각 채널마다 이 과정을 반복합니다.

## 7. `.env` 파일에 입력 — **사용자가 직접**

실행기는 `.env` 파일을 건드리지 않습니다(비밀값 보호 규칙). 아래 두 줄을
**본인이 직접** 저장소의 `.env` 파일에 입력해 주세요.

```
SLACK_BOT_TOKEN=xoxb-여기에-복사한-토큰
SLACK_ALLOWED_CHANNEL_IDS=C0123456789,G0123456789
```

- 채널이 여러 개면 쉼표(`,`)로 이어서 적습니다(공백 없이).
- webhook만 쓰고 싶다면(파일 전송·명령 수신 없이 보고만) `SLACK_WEBHOOK_URL`
  한 줄만 넣어도 됩니다. 하지만 파일 전송을 원하면 봇 토큰 방식이 필요합니다.

## 8. 실행기 재시작

`.env`를 바꾼 뒤에는 실행기를 재시작해야 반영됩니다.
(실행기 자체는 스스로 재시작하지 않으니, 평소 쓰시던 방법으로 꺼졌다 켜지게
해 주세요.)

## 9. 연결 점검

재시작 후 슬랙 채팅창에 `슬랙 점검` 이라고 보내세요. 실행기가
- 봇 토큰이 유효한지
- 허용한 채널마다 봇이 잘 들어가 있는지
- 확인 메시지가 잘 가는지

를 확인해서 `docs/reports/slack-check-YYYY-MM-DD.md` 파일로 결과를
정리해 슬랙으로 보내줍니다. "확인 필요"라고 나오면 5~6단계(앱 초대,
채널 ID)를 다시 확인해 주세요.

## 참고: 텔레그램도 같은 방식

텔레그램은 `.env`의 `TELEGRAM_BOT_TOKEN`·`TELEGRAM_ALLOWED_CHAT_IDS`를
넣고 재시작한 뒤 `텔레그램 점검`이라고 보내면 같은 방식으로 확인해 줍니다.
