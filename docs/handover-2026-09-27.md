## 4. 새로 만들 환경 (사용자 지시 2026-09-27 16:05) — V2R과 별개
**목표**: 글 발행을 V2R 실행기가 아니라 **여러 대의 가상 PC(원격 서버)** 에서 자동으로 하는 환경.
- 서버: RDCMan(Remote Desktop Connection Manager)으로 각 PC에 직접 연결해 관리. 그룹 예: "김성실대표님 가상피씨10개" 아래 1번에서 10번 PC(각 PC에 계정 번호 묶음 배정, 예: 1번 = 1에서 3번 댓글).
- 브라우저 조종: **Playwright, 반드시 창이 보이는(headed) 모드. 헤드리스 절대 금지.** 각 PC의 크롬을 사람이 쓰는 것처럼 조종.
- 원격 조종(리모컨): **Tailscale** 로 각 PC를 사설망에 묶고, 중앙에서 명령을 내려 각 PC의 크롬을 조종. **Cloudflare** 는 외부 진입점(터널/접근 제어) 역할, Tailscale 이 리모컨 역할.
- 감시·자가 복구: 각 PC 안에 **파이썬 모니터링 프로그램** 을 두어 발행 중 문제(로그인 풀림, 캡차, 창 닫힘, 네트워크 끊김 등)를 감지하면 스스로 복구하고, 안 되면 사람이 직접 개입할 수 있게 알림. **끝까지 임무 완수**가 목표(중단 없음).
- 아직 정해지지 않은 것(새 세션이 설계 단계에서 확정): PC 대수·OS, 중앙 명령 형식(V2R 채팅 명령 재사용 여부), 발행 대상 카페·계정 배정표, 알림 채널(슬랙 재사용 추정), 저장소 이름·위치(D:\v2r 자동화\ 아래 새 폴더 추정).
- 접속 주소·계정·비밀번호는 문서에 적지 않는다(RDCMan 저장분 사용).
