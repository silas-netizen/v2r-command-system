# V2R 자동 발행기 사용 설명서 (비개발자용)

이 글은 **컴퓨터를 잘 몰라도 따라 할 수 있게** 쓴 설명서입니다.
어려운 말이 나오면 그냥 "복사해서 붙여넣기"만 하시면 됩니다.

프로그램이 있는 폴더: `D:\v2r 자동화\v2r-command-system`

---

## 1. 시작하는 방법

### 방법 A. 컴퓨터를 켜면 저절로 시작 (이미 설정해 뒀습니다)

윈도우에 **작업 스케줄러**라는 알림장이 있습니다. 거기에 두 가지를 등록해 뒀습니다.

| 이름 | 언제 | 하는 일 |
|---|---|---|
| `V2R-Serve` | 컴퓨터에 로그인할 때마다 | 텔레그램 명령을 받는 실행기를 켭니다 |
| `V2R-Reconcile` | 매일 아침 8시 30분 | "끊긴 작업 점검"을 자동으로 돌립니다 |

그래서 **컴퓨터를 켜고 로그인만 하면** 텔레그램으로 명령을 보낼 수 있습니다.

### 방법 B. 손으로 지금 바로 켜기

탐색기에서 `scripts` 폴더로 들어가 **`serve.cmd` 를 두 번 클릭**하세요.
검은 창이 하나 뜨고, 텔레그램으로 이런 메시지가 옵니다.

> 실행기 시작됨. '상태' 라고 보내보세요

이 메시지가 오면 정상입니다. 이제 텔레그램에 명령을 보내면 됩니다.

> 실행기는 혼자 죽어도 **30초 뒤에 스스로 다시 켜집니다.** 걱정하지 않으셔도 됩니다.

---

## 2. 중지하는 방법

세 가지가 있고, 상황에 따라 다릅니다.

1. **지금 하는 일만 멈추기** → 텔레그램에 `중지` 라고 보냅니다.
   - 대기 중이거나 진행 중인 작업이 취소됩니다.
   - 실행기는 계속 켜져 있습니다. 다음 명령을 보내면 다시 일을 시작합니다.
2. **실행기 자체를 끄기** → `serve.cmd` 로 열린 검은 창을 닫습니다.
   - 작업 스케줄러로 켠 경우: 시작 → "작업 스케줄러" → 왼쪽 `작업 스케줄러 라이브러리` →
     `V2R-Serve` 에서 마우스 오른쪽 → **끝내기**.
3. **당분간 아예 안 켜지게** → 같은 자리에서 `V2R-Serve` 마우스 오른쪽 → **사용 안 함**.
   다시 쓰려면 **사용** 을 누르면 됩니다.

## 3. 텔레그램 명령 예시 20개

봇과의 대화방에 **한국어로 그냥 말하듯** 보내면 됩니다.
아래 문장을 그대로 복사해서 보내셔도 됩니다.

### 글 올리기

1. `일상 글 5개 올려줘`
2. `일상 글 20개 아이디 5개로 오전 9시부터 오후 6시까지 10분 간격으로 올려줘`
3. `고요한 아침에 일상 글 3개 올려줘`
4. `브랜드 글 올려줘`
5. `팥순이 브랜드 글 2개 올려줘`
6. `정보성 글 발행`
7. `일괄 발행 해줘`
8. `내일 오전 10시부터 일상 글 10개 올려줘`

### 자사 카페 일상 글 (카페별 한꺼번에)

```
자사 카페 일상 글 카페별 50건 실제 발행 댓글 랜덤
```

- `카페별 50건` — 우리 카페 **전부에 각각 50건**씩 올립니다(발행 제외로 표시한 카페는 뺍니다).
  카페 이름을 적으면(`고요한 아침 일상 글 카페별 50건 …`) 그 카페만 합니다.
- 글은 **예약하지 않고 바로 올립니다.** 한 건 올리고 **2~3분 쉬었다가** 다음 건을 올립니다.
  카페끼리는 나란히 진행합니다(50건이면 카페당 두 시간쯤). `2~5분 간격`처럼 적으면 그 값으로 바뀝니다.
- 원고는 `warehouse/inbox/sheets`의 각색 엑셀을 **오래된 파일부터, 위 행부터** 씁니다.
  다 떨어지면 일상 글 풀을 씁니다. 이미 올린 글은 본문이 같기만 해도 건너뜁니다.
- 계정은 그 카페에서 글을 쓸 수 있는 계정 **5~10개를 골라 돌려 씁니다**(같은 계정 연속 사용 안 함).
- `댓글 랜덤` — 글마다 댓글을 **0~3개 랜덤**으로 답니다(절반은 0개). 글쓴이가 아닌 카페 회원이
  글 올린 뒤 3~120분 사이에 답니다. 댓글 문구를 못 만들면 **댓글 없이 글만** 올라갑니다.
- `실제 발행`을 빼면 모의 실행입니다(계획만 보여주고 아무것도 올리지 않습니다).
- 끝나면 텔레그램으로 **카페별 성공/실패 수**를 알려주고, `docs/reports/self-daily-<날짜>.md`에
  표(카페·게시판·계정·시각·댓글 수·주소)를 남깁니다.
- 도중에 실행기가 꺼져도 괜찮습니다. 같은 명령을 다시 보내면 **남은 글부터** 이어서 올립니다.

### 살펴보기 · 점검하기

9. `상태` — 지금 무슨 일이 돌고 있는지 알려줍니다.
10. `진행 상황 알려줘` — 9번과 같습니다.
11. `끊긴 작업 점검` — 도중에 끊긴 글이 실제로 올라갔는지 확인합니다.
12. `실패 글 점검해줘` — 실패한 글을 모아서 보여줍니다.
13. `카페 목록 보여줘`
14. `고요한 아침 게시판 목록 보여줘`

### 멈추기

15. `중지` (또는 `멈춰`, `그만`)

### 원본(시트) 다루기

16. `시트 갱신해줘` — 구글 시트 / 엑셀에서 원고를 새로 읽어옵니다.
17. `전체 원본 지금 동기화` — 모든 원본을 한 번에 새로 읽어옵니다.

### 사진 다루기

18. `사진 가져와` — `warehouse\inbox` 에 넣어 둔 사진을 창고로 들입니다.
19. `사진 세탁 3장씩` — 원본 1장당 조금씩 다른 사진 3장을 만들어 둡니다.
20. `브랜드 팥순이 키워드 단호박 사진 요청` — 부족한 사진을 만들어 달라는 요청서를 보냅니다.

### 더 알아두면 좋은 명령

- `새 사진 수거` — 요청해서 새로 받은 사진을 창고에 넣고 세탁까지 합니다.
- `일상 글 30개 만들어줘` — 올릴 일상 글을 미리 만들어 쌓아 둡니다.
- `고아 글 정리` — 일상 글만 올라가고 본 글이 안 만들어진 **찌꺼기**를 찾아 줍니다.
  (기본은 **보여주기만** 하고 지우지 않습니다. 아래 4번 항목 참고)
- `로그인 창 열어줘` — V2R 사이트 로그인 상태를 확인합니다.

## 4. 아주 중요한 규칙: "실제 발행"

**기본은 연습(모의 실행)입니다.** 그냥 명령을 보내면 진짜로 올라가지 않고,
"이렇게 올릴 예정입니다" 하는 계획만 보여줍니다. 안전장치입니다.

**진짜로 올리려면 문장 끝에 `실제 발행` 이라고 붙여야 합니다.**

- 연습: `일상 글 5개 올려줘` → 실제로 안 올라감
- 진짜: `일상 글 5개 올려줘 실제 발행` → **진짜로 올라감**

`바로 발행`, `실제 등록`, `바로 등록` 도 같은 뜻입니다.
이 문구가 없으면 무슨 일이 있어도 진짜로 올라가지 않습니다.

`고아 글 정리` 도 똑같습니다. `고아 글 정리` 는 목록만, `고아 글 정리 실제 발행` 은 **진짜 삭제**입니다.

## 5. 결과 메시지 읽는 법

명령을 보내면 보통 **두 번** 답이 옵니다.

1. 접수했다는 답: `작업 51 진행: 일상 글 발행, ... 모의 실행`
2. 끝났다는 답: `작업 51 완료: 일상 글 발행, ...`

메시지 첫머리 단어만 보면 됩니다.

| 보이는 말 | 뜻 | 할 일 |
|---|---|---|
| **진행** | 접수해서 지금 하고 있음 | 기다립니다 |
| **완료** | 잘 끝났음 | 없음 |
| **실패** | 못 했음. 뒤에 사유가 붙습니다 | 사유를 보고 6번으로 |
| **불확실** | 올라갔는지 아닌지 모름 | `끊긴 작업 점검` 을 보냅니다 |

자주 나오는 사유와 뜻:

- `모의 실행` — 연습이었다는 뜻. 진짜로 올리려면 `실제 발행` 을 붙이세요.
- `발행할 원고가 없습니다` — 시트에 쓸 원고가 없습니다. `시트 갱신해줘` 부터 하세요.
- `사진이 부족합니다` — 사진 창고가 비었습니다. 7번(사진 폴더)을 보세요.
- `쓸 수 있는 계정이 없습니다` — 계정이 제한에 걸렸습니다. 조금 뒤 다시 하세요.
- `명령을 해석하지 못했습니다` — 말을 못 알아들었습니다. 위 3번의 예시 문장으로 다시 보내세요.

## 6. 뭔가 이상할 때, 이 순서대로 확인하세요

### ① 텔레그램에 `상태` 를 보내 본다

답이 오면 실행기는 살아 있습니다. 답이 **안 오면** 실행기가 꺼진 것입니다 → ②로.

### ② 실행기를 다시 켠다

`scripts\serve.cmd` 를 두 번 클릭합니다.
`실행기 시작됨...` 메시지가 오면 해결된 것입니다.

### ③ 기록(로그)을 열어 본다

기록 파일은 여기 있습니다. 메모장으로 열면 됩니다.

| 파일 | 내용 |
|---|---|
| `logs\serve.log` | 실행기가 한 일 전부. 문제가 있으면 여기 남습니다 |
| `logs\reconcile.log` | 매일 아침 자동 점검 결과 |

**맨 아래 몇 줄**만 보면 됩니다. `Traceback`, `Error`, `실패` 같은 말이 있으면
그 부분을 그대로 복사해서 담당자에게 보내 주세요.

### ④ 설정 파일(`.env`)을 확인한다

폴더 맨 위의 `.env` 파일에 비밀번호와 열쇠가 들어 있습니다.
**절대 남에게 보여주거나 캡처해서 보내지 마세요.** 확인할 것은 이것뿐입니다.

- `TELEGRAM_BOT_TOKEN` 줄이 있는가 (값은 보지 않아도 됩니다)
- `TELEGRAM_ALLOWED_CHAT_IDS` 에 내 대화방 번호가 있는가
- `V2R_EMAIL`, `V2R_PASSWORD` 줄이 있는가

이 중 하나라도 줄 자체가 없으면 담당자에게 알려 주세요.

### ⑤ 그래도 안 되면 다시 시작

검은 창을 모두 닫고 `scripts\serve.cmd` 를 다시 두 번 클릭합니다.
그래도 안 되면 컴퓨터를 껐다 켭니다(로그인하면 저절로 다시 켜집니다).

## 7. 사진은 어디에 넣나요

사진은 **`warehouse\inbox`** 폴더에 넣습니다.

```
D:\v2r 자동화\v2r-command-system\warehouse\inbox\
```

이 안에 **브랜드 이름 폴더**를 만들고, 그 안에 **주제 폴더**를 만들어 넣으세요.

```
warehouse\inbox\
  팥순이\
    단호박\   ← 여기에 사진 파일을 넣습니다
    팥죽\
  코숨핏\
    운동복\
```

넣은 다음 텔레그램에 **`사진 가져와`** 라고 보내면 창고로 들어갑니다.
이어서 **`사진 세탁 3장씩`** 을 보내면 원본 1장당 조금씩 다른 사진 3장을 만들어 둡니다
(같은 사진을 여러 번 올리지 않기 위해서입니다).

브랜드 폴더 없이 사진만 넣으면 `공용` 으로 들어갑니다. 되도록 폴더를 만들어 주세요.

## 8. 한 장 요약

| 하고 싶은 일 | 하는 법 |
|---|---|
| 켜기 | `scripts\serve.cmd` 두 번 클릭 (또는 컴퓨터 로그인) |
| 끄기 | 검은 창 닫기 |
| 지금 일만 멈추기 | 텔레그램에 `중지` |
| 진짜로 올리기 | 명령 끝에 `실제 발행` 붙이기 |
| 상태 보기 | 텔레그램에 `상태` |
| 사진 넣기 | `warehouse\inbox\브랜드\주제\` 에 넣고 `사진 가져와` |
| 문제 확인 | `logs\serve.log` 맨 아래 몇 줄 |
