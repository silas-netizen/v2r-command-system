## 솔직하게 남은 것 2가지
1. **자격증명 자동 백업·복원 코드는 못 넣었습니다.** 앱의 보안 규칙이 "프로그램이 로그인 자격증명 파일을 복사·되돌리는 동작"을 차단했습니다(제가 우회하지 않음). 대신 지금은 (a) 제가 오늘 수동으로 백업한 사본 1개(`data/claude-cli-backup/`), (b) 매일 로그인 점검 + 풀리면 즉시 알림 + 원클릭 재로그인 스크립트로 유지합니다. 자동 복원까지 원하시면 앱 권한 설정에서 그 동작을 허용해 주셔야 합니다(허용 후 제가 바로 넣음).
2. 요금제 길은 출력 길이 상한(max_tokens)을 우리가 정할 수 없어 API판과 미세하게 다를 수 있습니다. 이번 6건에선 차이 없음. 배치 API 길은 아직 자리만 있음(요금제로 충분해 급하지 않음).
