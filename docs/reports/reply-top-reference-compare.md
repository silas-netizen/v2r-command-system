# 비교군 추가 — 기존 지침 원고 vs 참고 형식 원고 (2026-09-23)

같은 5개 키워드(브랜드별 검색량 최상위 1개)로 두 가지를 모두 만들어 나란히 비교합니다.

| 구분 | 만드는 방법 |
|---|---|
| 기존 지침 원고 | 지금까지의 브랜드 가이드·규칙만으로 생성(참고 형식 없음) |
| 참고 형식 원고 | 같은 가이드 + 통검 1등 글 형식 요약을 붙여 생성 |

## 보고서에 들어갈 것

- 키워드별 3열 비교표: **1등 글 형식 / 기존 지침 원고 / 참고 형식 원고** — 제목 유형, 글자수, 단락 수, 도입 방식, 전개 순서, 마무리 유형, 규칙 검증 통과 여부, GPT 교차검증 점수.
- 두 원고의 본문 첫 3~4문장 나란히 인용(우리 원고만, 1등 글 원문은 인용하지 않음).
- 토큰 사용량 증가분(참고 형식 요약 300~400자가 건당 얼마나 더 드는지).
