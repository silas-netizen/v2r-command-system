# 노출 검사 시 시트 갱신 규칙 — 정정판 (2026-09-23 19:45)

스크린샷 기준으로 다시 정했습니다. B~F열은 숨김 열이므로 **건드리지 않습니다**.

| 열 | 내용 | 검사 후 처리 |
|---|---|---|
| A 카페 | 우리 글이 확정된 카페명 | 노출완이면 갱신, 밀려남이면 기존값 유지 |
| B~F (숨김) | — | 변경 없음. E 비밀번호는 읽지도 쓰지도 기록하지도 않음 |
| G 노출 상태 | 노출완 / 밀려남 / 미확인 | 매 검사 갱신 |
| H 키워드 | — | 변경 없음 |
| I 통합검색 | 통검 링크 | 비어 있을 때만 채움 |
| J 최종 편집 일시 | 이번 노출 검사 시각 | 매 검사 갱신 |
| K 키워드 검색량 | 키워드 도구 모바일+PC 합 | 매 검사 최신화 |
| L 노출된 검색량 | 노출완이면 K, 밀려남이면 0 | 매 검사 갱신 |

- 쓰기 방식은 A / G / J~L 을 나눠 쓰는 안과 한 줄 통과 안을 비교해 **숨김 열을 전혀 통과시키지 않는 쪽**을 택하고 이유를 보고서에 적습니다.
- 팥순이 처음 10개 행으로 실제 1회 적용해 전후 비교를 보고서에 넣고, 이후 노출 순환의 시트 반영이 이 규칙으로 돕니다(실행기 재시작 후).
- 상단 P2 표(키워드 총 검색량/노출 키워드 총 검색량)는 함께 갱신됩니다.
