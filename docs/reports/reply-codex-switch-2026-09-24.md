## 왜 문제 없나
- Codex는 채점·검증 **호출만** 합니다. 결과(점수·당위성 논리)는 전부 우리 키워드 DB와 원고 JSON에 저장되고, 어느 계정으로 호출했는지는 결과에 영향이 없습니다.
- 대기 중인 30,074개 교차검증도 "아직 GPT 점수가 없는 행"을 기준으로 이어가므로 계정이 바뀌어도 그 자리부터 계속됩니다.
- 모델(gpt-6-astra / gpt-5.6-sol)은 계정과 무관한 설정값입니다. 새 계정에 해당 모델 권한이 없으면 대체 모델로 자동 넘어갑니다.

## 바꾸는 절차(사용자가 PC에서)
1. Codex CLI 로그아웃 → 새 ChatGPT 계정으로 로그인(제가 로그인 입력은 하지 않으므로 직접 해 주셔야 합니다. 로그인 창은 사용자가 여는 것이므로 "창 금지" 규칙과 무관).
2. 로그인 후 "코덱스 계정 바꿨어"라고만 알려 주시면 제가 보류 파일을 지우고 재채점 병렬 5개가 즉시 교차검증을 재개하도록 합니다. 새 계정으로 첫 호출이 정상인지 1건 확인 후 보고.
