# 바꾼 규칙 (2026-09-21) — 상황 연출 폐지 / 대대댓글2 재설계 / 길이 200%

## 1. 페르소나·상황 연출을 통째로 뺐다

- `brand_writer.PERSONA_SEEDS` (16종)와 `persona_for()` **삭제**.
  본문 프롬프트에 더 이상 나이대·직업·"글 쓰는 시각"을 심지 않는다.
- 대신 절대 규칙 `NO_SCENE_RULE` 을 본문 프롬프트 맨 앞에 박았다.
  - 기존 완성 원고처럼 **문제 상황(증상·고민)부터 바로** 시작한다
  - 글 쓰는 장소·시간·상태를 묘사하지 않는다
- 검증기에 `상황 연출 금지` 항목을 새로 넣었다 (**하드 실패 → 재생성**).
  금칙 패턴: 글 남겨요 / 글 써요 / 글 씁니다 / 한산해(한) / 잠깐 앉아 /
  쓰는 중이에요 / 끄적 / 적어봐요 / 적어보는 / 올려봐요 등
  (`SCENE_BANNED_PHRASES`, 제목·본문에만 적용 — 댓글의 "이거 쓰는 중"은 정상이라 뺐다)

## 2. 대대댓글2를 기존 원고 구조로 되돌렸다

예전에는 "60자 안쪽" 같은 **길이부터** 못 박아서 모델이 문장을 조각냈다.
그래서 `팥순ㅇㅣ요 … 참기만 하면 제자리 농촌진흥청 25% 검증 검색해봐요` 같은
명사 나열이 나왔다. 이제는 구조와 문장이 먼저다.

질문형 틀 (`reply2_prompt_block`)

1. `<제품명>(이)라고 있어요` — 제품을 먼저 꺼낸다
2. 왜 믿을 만한지 **완전한 문장 하나** (권위기관 / 검증 / 원리)
3. 다른 방법으로는 왜 안 되는지 한 문장
4. `검색해보시면 후기 많아요` 류 마무리

검증 (`reply2_problems`, 전부 하드)

| 항목 | 기준 |
| --- | --- |
| 제품 표기 | 팥순이는 `팥순ㅇㅣ` 포함 |
| 근거 문장 | 권위·검증·원리 낱말 1개 이상 (`REPLY2_EVIDENCE_WORDS`) |
| 대안의 한계 | 그냥/만으로는/한계/잠깐/도루묵/제자리/소용없 등 (`REPLY2_LIMIT_WORDS`) |
| 검색 유도 | `검색` 또는 `찾아보` |
| 문장 | 완전한 문장 3~4개, 모두 서술 어미(요/에요/더라구요…)로 끝남 |
| 조각 금지 | 한 어절짜리 문장 금지, 조사 없는 명사가 4개 이상 연달아 붙으면 탈락 |
| 근거 도용 | 팥순이 근거(농촌진흥청·체지방 25%)를 다른 브랜드가 쓰면 탈락 |
| 그 외 | 금칙어 / 이모지 / 기존 예시와 90% 이상 유사 금지 |

후기형은 역할이 달라 따로 본다 (`review_reply2_problems`):
여분 계정이 `저도 이거 먹는 중` + 기간·감량 수치 + 정부기관 체지방 25% 결과,
제품명은 다시 쓰지 않고 `이거` 로 받는다.

## 3. 글자 수는 상한의 200%까지 통과 (사용자 지시)

- `LENGTH_TOLERANCE = 2.0`, `SOFT_LIMIT_FACTOR = 2.0`
- 본문·댓글 **모두** 상한의 200%를 넘을 때만 실패. 그 이하는 **경고도 내지 않는다**
  (경고가 재시도를 불러 글 완성도를 깎던 문제를 없앴다).
- 대대댓글2 상한은 60 → **110자** (`REPLY2_MAX_LEN`), 실제 실패선은 220자.
  실험실 후보는 60자 미만만 탈락시킨다.
- 프롬프트에서는 길이를 "예시와 비슷한 길이감" 정도로만 말하고,
  "길이를 맞추려고 조사나 서술어를 빼지 마라" 를 덧붙였다.

## 3-2. 골든 문장 · 브랜드 고유 논리 (2차 반영)

- 사용자가 고른 문장을 `config/reply2_golden.yaml` 에 저장한다
  (우아덤 3 / 코숨핏 3 / 팥순이 질문형 4 / 팥순이 후기형 4).
  본 생성기와 실험실 **둘 다** 이 문장을 대대댓글2 few-shot의 **맨 앞**에 놓고
  "이 구조와 논리를 반드시 따른다"고 못 박는다 (시트 예시보다 우선).
- `BrandRule.reply2_logic` (`ReplyLogic`) 로 브랜드 고유 논리를 검증한다.
  - 장으뜸: `흡수 / 작용 / 배합 / 함량` 중 **2개 이상**
    — "아무거나 먹으면 흡수·작용이 안 돼서 소용없고 배합·원물 함량을 봐야 한다"
  - 뉴더미스: `보호막 / 강화 / 성분` 중 **2개 이상** + `소용없 / 의미없 / 한계 / 그때뿐 / 재발`
    중 하나 — "보호막 강화 성분이 없으면 그냥 씻기만 하는 거라 소용없다"
- 팥순이 후기형: 감량 수치는 **8kg 이상**만 통과 (`REVIEW_MIN_KG`).
  같은 유형은 "기존 예시와 같아도 된다"는 결정에 따라 **베끼기(유사도) 검사를 뺐다**.

## 3-3. 근거 문장에는 웃지 않는다 (2026-09-22)

`의사분들이 추천하는 보호막 강화 성분이 들어있어요 ㅋㅋㅋㅋ` 처럼 권위·근거를
말하면서 웃어 버리면 그 말의 신뢰가 깎인다.

- **댓글2·대대댓글2**에서 근거를 말하는 문장(의사·기관·논문·검증·성분·원리)에
  `ㅋㅋ ㅎㅎ` 를 붙이면 **실패 → 그 댓글만 재생성** (`근거 문장 웃음 표기`).
- `ㅋㅋ ㅎㅎ` 는 **다른 방법의 한계 문장**이나 **마지막 검색 유도 문장**에서만 쓴다.
- `ㅠㅠ` 는 웃는 것이 아니라 안타까움이라 **근거 문장에 붙어도 된다**
  (사용자 지시 2026-09-22).
- 띄어 쓴 웃음(`성분이에요 ㅎㅎ`)도 **앞 문장에 붙은 것**으로 본다
  (`reply2_sentences` 가 그렇게 묶는다).
- 골든 문장도 같은 기준으로 훑어 근거 문장 옆 웃음만 지웠다
  (`strip_evidence_laughter`, 문장 자체는 그대로).

## 4. 대대댓글2 전용 실험실

    python -m v2r.content.reply2_lab --brand 전체 --type 질문형 --n 5

- `data/brand_sheet_<브랜드>.xlsx` 완성 행에서 기존 대대댓글2를 전부 모아
  검증을 가장 잘 통과하는 8개를 few-shot으로 붙인다
- 본문·키워드는 `warehouse/manuscripts/generated-plan/<브랜드>/*.json` 에서 읽는다
- 통과 후보가 N개가 될 때까지 최대 10판 다시 요청하고, 탈락은 사유와 함께 남긴다
- 결과: `docs/reports/reply2-candidates-<날짜>.md`
