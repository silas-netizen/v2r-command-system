# GPT는 요금제(ChatGPT 구독)로 쓰나 (2026-09-24 10:44)

네. Codex CLI가 **ChatGPT 계정 로그인 방식(auth_mode: chatgpt)** 으로 동작해 구독 요금제 한도 안에서 씁니다. API 키 종량제가 아닙니다.

- 클로드 채점·원고 = Claude Code 요금제(0원), GPT 교차검증·감사 = ChatGPT 요금제(0원 추가 비용).
- 한도에 걸리면(요금제 한도 정지) 채점은 10분 쉬고 자동 재개하고, 원고 교차검증은 "미검증"으로 넘겨 생성을 막지 않습니다.
- 로그인은 유지 상태이며 풀리면 재로그인 요청 없이 먼저 자동 복구를 시도합니다(기존 규칙).
