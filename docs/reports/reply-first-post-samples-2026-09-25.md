## 2. 사진 선택과 세탁 — 기억합니다(2026-09-19 확정)
- **선택**: 브랜드/키워드 폴더(warehouse/images)의 사진만. 폴더가 비었거나 부족하면 GPT 웹(요금제, API 아님)으로 생성 — 생성 전 승인 요청("사진 생성 승인 브랜드 키워드 N장") → 결과 사진을 보내 승인/반려 받은 뒤에만 사용. 장으뜸은 GPT 생성 금지(폴더 사진 랜덤). 브랜드 루트 사진은 씨앗으로만.
- **생성 기준**: 1K 화질, 인위적 AI 티 절대 금지, 연출된 상차림·소품·사람 구도 금지, 음식(제품) 클로즈업 위주. GPT 대화창은 사진용 1개를 이어 씀.
- **세탁**: EXIF 날짜·카메라 정보 랜덤 변경 → 약한 그레인 + JPEG 품질 92에서 95만(회전·모션 블러·강한 노이즈·저품질 금지) → 가로 400px 이하로 축소(비율 유지, 확대 금지). 세탁본은 warehouse/images/washed/ 아래에만 두고, **원본은 절대 첨부하지 않음**.
- **배치**: 팥순이 질문형 2번째 문단 뒤 {키워드}, 후기형 1번째 문단 뒤 {키워드}+{B/A}; 나머지 브랜드 2번째 문단 뒤 {키워드}. 태그는 키워드 공백 제거 1개.
- 이번 20건: 뉴더미스·장으뜸·코숨핏·우아덤 키워드 폴더를 먼저 확인하고, 없는 키워드는 승인 후 생성.
