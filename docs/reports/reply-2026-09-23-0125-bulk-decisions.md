# 대량 원고 — 결정 반영·처리량 계산 (2026-09-23 01:25 KST, 실측)

## 반영
1. 대기열은 자동 적재, **대량 생성은 명령할 때만**(`우아덤 대량 원고 5건`, `대량 원고 전체 3건`). 자동 예약은 꺼 둠. 소량 테스트 준비 완료되면 알려 드립니다.
4. 제휴 카페 상한 = **씨씨앙 20 · 양평맘 10 · 쌍둥이맘 20 = 하루 50건**, 각 일상 글 뒤 +4h/+20h/+22h 수정 발행. 설정에 고정.

## 3번 답: "속도"는 그냥 하루 생성 건수 차이였습니다
- 0원(요금제)만: 하루 약 300건 생성 가능(추정, 실측 후 갱신). 유료 배치 병행: 하루 1,000건 이상.
- 그런데 발행 상한이 하루 50건이므로 **300건도 남습니다 → 유료 병행 필요 없음, 0원만 사용**으로 결정.

## 2번: 하루 할당 계산
| 항목 | 값 |
|---|---|
| 하루 발행 | 50건(카페 상한 합) |
| 하루 생성 목표 | 60건(검증 탈락·재시도 여유 20%) |
| 준비 재고 | 3일치 150건까지만(넘으면 생성 중단) |
| 브랜드별 일일 할당(기본, 밀려남 수 비례) | 우아덤 20 · 팥순이 14 · 장으뜸 9 · 코숨핏 4 · 뉴더미스 3 = 50 |
| 8,355건 소진 기간 | 약 167일(하루 50건 기준) — 발굴로 늘어나는 밀려남은 노출 순환이 우선순위(검색량)로 정렬 |
- 브랜드별 할당은 설정 파일에서 바꿀 수 있고, "브랜드별 몇 건"이라고 말씀하시면 그대로 고정합니다.
- 카페 배정: 브랜드 원고 50건을 3개 카페(20/10/20)에 검색량 큰 원고부터 나눔, 같은 카페에 같은 브랜드가 하루 상한의 절반을 넘지 않게(카페당 브랜드 섞기). 계정은 카페별 제휴 계정(97/87/31개)에서 하루 1건씩 순번.
