# 2차 선택 반영 (2026-09-22 02:25 KST)

## 골든 추가
- 장으뜸 2차 3·5번, 뉴더미스 2차 1~5번 → `config/reply2_golden.yaml`에 추가 중.

## 새 규칙(즉시 적용)
- **권위·근거 문장(의사·기관·검증·성분·원리) 바로 옆에 ㅋㅋ/ㅎㅎ/ㅠㅠ 금지** — 신뢰가 떨어짐. 웃음 표기는 대안 한계 문장이나 마무리(검색 유도)에서만.
- 검증기: 근거 문장에 웃음 표기가 붙으면 그 댓글만 재생성.
- 골든 저장본도 같은 기준으로 정리: 뉴더미스 3번 "…들어있어요 ㅋㅋㅋㅋ" → 제거, 2번 "세정제에요 ㅎㅎ" → 제거, 장으뜸 5번 "흡수가 잘된대요ㅎㅎ" → 제거(문장은 그대로). 다른 골든도 점검.

반영 끝나면 최종 골든 목록을 보내고, 이어서 브랜드별 원고 1건씩(페르소나 없이·골든 적용) 최종 확인용 생성으로 넘어갑니다.
