# Windows Script Host 오류창 원인·해결 (2026-09-23 16:17)

## 무엇이었나

연관도 재산정이 끝나 **원고 대상 키워드를 5개 브랜드 시트에 반영**하는 작업을 창 없이 돌리려고, 숨김 실행용 작은 스크립트(.vbs)를 제가 즉석에서 만들었습니다. 그 파일 한 줄의 따옴표를 잘못 써서(VBScript 문법 오류) 실행 즉시 **오류창이 두 번** 떴습니다. 스크립트 자체가 실행되지 않았으므로 다른 영향은 없습니다.

## 조치

- 따옴표를 바로잡고(기존 실행기 숨김 스크립트와 같은 형식), 다시 띄웠습니다. 이제 창 없이 돌아갑니다.
- 재발 방지: 앞으로 즉석 실행 스크립트는 저장소에 이미 검증된 `scripts/serve-hidden.vbs` 형식을 복사해서만 쓰고, 처음 실행은 오류창이 뜨지 않는 `cscript //nologo` 방식으로 합니다.

## 지금 돌아가는 것

시트 키워드 반영(5개 브랜드, 클로드·Codex 둘 다 0~2점인 원고 대상 키워드를 시트 두 번째 탭에 추가). 끝나면 브랜드별 추가 건수를 보고합니다.
