# "V2R 시트 쓰기" 이전 코드는 무엇이었나 (2026-09-25 11:52)

## 정체
9월 22일 밤 제가 만든 **같은 목적의 첫 번째 웹앱**입니다(그때 "시트 쓰기에 구글 인증이 필요하니 Apps Script 웹앱을 사용자 계정에 배포하자"고 제안 → 사용자가 승인 창을 닫고 진행하지 않아, 대신 브라우저 조작 방식으로 갔고 그 방식이 지금까지 사고를 냈습니다). 코드는 저장만 됐고 **배포된 적 없음**, 우리 시스템 어디에도 그 URL이 연결돼 있지 않습니다.

## 지워도 되나 — 네
- 기능은 새 코드가 전부 포함하고 더 안전합니다: 허용 시트 5개 고정(임의 시트 ID 거부), 허용 작업 4개(추가·키워드로 갱신·키워드로 삭제·스냅샷), **B에서 F열 쓰기 금지·비밀번호 열 제거**, 새 행에 2행 서식·드롭다운 자동 복사, 동시 요청 잠금.
- 이전 코드는 임의 시트·임의 셀(set_cells)·임의 범위 덮어쓰기(update start_row)를 허용해 오히려 위험합니다.

## 그대로 진행
1. 그 코드를 전부 지우고(Ctrl+A → Delete) 제가 드린 코드 붙여넣기 → Ctrl+S.
2. 배포 → 새 배포 → 웹 앱(나 / 모든 사용자) → 배포 → 승인 → **웹 앱 URL** 채팅에 붙여넣기.
