# 1위 글은 카페 글만 — 재검증 (2026-09-23)

정정 반영: 참고 대상은 통검에서 **첫 번째 카페 글**로 한정합니다(블로그·포스트·지식iN 제외, 광고·쇼핑·뉴스 제외).

## 다시 하는 일

1. 선택 규칙을 카페 전용으로 변경(설정 `top_reference.sources: [cafe]`). 첫 페이지에 카페 글이 없으면 참고 없이 기존 방식.
2. 15개 키워드 1등 카페 글 재수집 — 전체 순번·일반 글 순번·카페 중 순번, 다른 방식으로 한 번 더 받아 첫 카페 글 일치 여부 교차검증.
3. 5개 키워드의 참고 형식 원고를 새 카페 기준으로 재생성(기존 지침 원고는 그대로). 카페 글이 없는 키워드는 같은 브랜드의 다음 검색량 키워드로 대체.
4. 두 보고서 갱신: [시험 결과](file:///D:/v2r%20%EC%9E%90%EB%8F%99%ED%99%94/v2r-command-system/docs/reports/top-reference-2026-09-23.md) · [원고 전문 비교](file:///D:/v2r%20%EC%9E%90%EB%8F%99%ED%99%94/v2r-command-system/docs/reports/top-reference-manuscripts-2026-09-23.md)

앞서 보낸 결과는 블로그 글이 1위로 잡힌 것이어서 무효로 보시면 됩니다.
