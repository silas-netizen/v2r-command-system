# "우선순위 재검사"란 (2026-09-24 00:02)

5만 개 키워드를 매번 똑같이 처음부터 끝까지 도는 대신, **상태가 바뀔 가능성이 높은 키워드를 더 자주, 바뀔 일이 적은 키워드는 덜 자주** 확인하는 방식입니다. 전체를 무한 순환하는 원칙은 그대로이고, 순서와 주기만 다르게 둡니다.

## 확인 주기 (제안)

| 순위 | 대상 | 주기 | 이유 |
|---|---|---|---|
| 1 | 새로 발굴돼 아직 한 번도 확인 안 한 키워드 | 즉시(가장 먼저) | 시트 G열이 "미확인"이라 채워야 함 |
| 2 | 우리 글이 새로 발행된 키워드(발행 후 4시간·1일·3일) | 발행 직후 | 노출 여부를 빨리 알아야 재발행·수정 판단 가능 |
| 3 | 현재 **노출완** 키워드 | 매일 1회 | 밀려나는 순간을 놓치지 않기 위해 |
| 4 | **밀려남**이고 검색량 상위(브랜드별 상위 30%) | 2~3일마다 | 대량 원고 대상이라 상태 변화가 중요 |
| 5 | 밀려남이고 검색량 하위 | 주 1회 | 바뀔 가능성 낮고, 바뀌어도 영향 작음 |
| 6 | 연관도 3(무관, 원고 대상 아님) | 확인 안 함 또는 월 1회 | 우리 원고가 없어 노출될 일이 없음 |

## 효과

- 5개 브랜드 5만 개 중 원고 대상(연관도 0~2)은 약 1.4만 개, 그중 노출완은 수백 개 수준 → **하루 실제 검사량 1~2만 건 → 필요하면 5천 건 안팎**으로 줄어듭니다.
- 그래서 병렬을 5개까지 올리지 않아도(2~3개, 시간당 300~500건) 중요한 키워드는 매일, 나머지도 주 1회 안에 다 돕니다. 네이버 차단 리스크도 그만큼 줄어듭니다.

## 유지되는 원칙

- 모든 키워드는 결국 순환 안에 있음(무한 순환 업무).
- 검사 시각(J열)이 오래된 순으로 같은 등급 안에서 돌기 때문에 빠지는 키워드 없음.
- 주기 숫자는 설정 파일 한 곳에서 바꿀 수 있게 둡니다.

주기 표가 마음에 안 드시면 숫자를 말씀해 주시면 그대로 넣겁니다.
