# 크롬 프로필 유지 여부 (2026-09-21 14:15 KST)

## 솔직한 답
- **크롬 안의 로그인 상태(구글 등)를 제가 직접 들여다보진 못했습니다.** 크롬 확장이 연결돼 있지 않고, 크롬 프로필의 쿠키를 프로그램으로 여는 건 사생활 영역이라 하지 않습니다.
- 대신 **건드리지 않았다는 증거**는 확인했습니다.

| 항목 | 결과 |
|---|---|
| 크롬 프로필 폴더(`Chrome\User Data\Default, Profile 1~3`) | 그대로 존재. 우리 프로그램은 이 폴더를 **한 번도 쓰지 않음** |
| 우리 프로그램 전용 프로필 | 완전히 별도 폴더 `data/browser-profile-naver`, `-gpt`, `browser-profile`(V2R용). 크롬 실행 파일만 빌려 쓰고 프로필은 우리 폴더 |
| 크롬 실행 상태 | 지금 크롬 프로세스 9개 실행 중(사용자가 열어 둔 크롬), 최근 사용 프로필 `Profile 1`이 오늘 12:02에 갱신됨 = 정상 사용 중 |

## 결론

- 100% 확인을 원하시면: 크롬 창 오른쪽 위 계정 아이콘에 프로필 사진이 보이면 유지 중입니다. 또는 크롬 확장을 연결해 주시면 제가 직접 확인해 드립니다.
