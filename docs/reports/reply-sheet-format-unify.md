# 새 키워드 행의 드롭다운·서식 통일 (2026-09-24 00:35)

## 문제

오늘 시트에 추가한 키워드 행(우아덤 181·장으뜸 283·뉴더미스 451건)은 값만 붙여넣어 A(카페)·G(노출 상태) 열에 **드롭다운이 없고** 색·정렬 서식도 기존 행과 다릅니다.

## 조치

| 항목 | 내용 |
|---|---|
| 새 행 추가 시 | 값을 넣은 뒤 기존 행(2행)의 **서식만 붙여넣기 + 데이터 확인(드롭다운)만 붙여넣기**를 자동 적용. 값은 덮어쓰지 않음 |
| 이미 들어간 행 | 우아덤·장으뜸·뉴더미스(해당되면 팥순이·코숨핏)에서 드롭다운 없는 새 행 구간을 찾아 같은 방식으로 보정. 전후 export 비교로 값이 하나도 바뀌지 않았음을 확인 |
| 확인 | 셀의 드롭다운 표시를 화면 구조로 확인하고 스크린샷 1장 첨부 |
