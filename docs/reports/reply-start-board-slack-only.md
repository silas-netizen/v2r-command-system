# 일상 글 시작 현황판 · 슬랙 전용 푸시 · 컨텍스트 1M 복원 (2026-09-23)

## 1. 일상 글 시작 현황판 (슬랙)

일상 글 발행 작업이 **시작될 때** 계획이 잡히는 즉시 아래 형태의 현황판 한 장을 📢 아이콘으로 보냅니다. 방금 오늘 실적(작업 167)으로 만든 표본을 슬랙 `카페-클로드`에 1건 보냈으니 모양을 확인해 주세요.

```
📢 일상 글 시작 현황판 (09-23 09:15, 작업 167)
총 100건 · 카페 5곳 · 계정 10개 · 간격 2~5분
• 송도포털: 22건 · 게시판 14개 · 계정 9개
• 러브 인썸: 21건 · 게시판 17개 · 계정 10개
• …
오늘 계정: arc0108, cambrude, doansli, …
```

- 구현: [worker.py](file:///D:/v2r%20%EC%9E%90%EB%8F%99%ED%99%94/v2r-command-system/v2r/engine/worker.py) `_daily_start_board` — 실제 발행(모의 실행 제외)인 일상 글 작업에만 붙습니다.
- 내용: 총 건수, 카페 수, 계정 수, 간격 / 카페별 건수·게시판 수·계정 수 / 오늘 돌려 쓰는 계정 10개 목록.

## 2. 텔레그램 푸시 중지, 슬랙만

- [notify.yaml](file:///D:/v2r%20%EC%9E%90%EB%8F%99%ED%99%94/v2r-command-system/config/notify.yaml)에 `push_channels: [slack]` 추가. 보고·경고·현황판·파일 전송이 **슬랙으로만** 나갑니다.
- 텔레그램은 **명령 수신과 그 명령에 대한 직접 답장은 그대로** 됩니다(푸시만 멈춤). 다시 켤 때는 이 줄에 `telegram`을 넣거나 줄을 지우면 되고, 실행기 재시작 없이 60초 안에 반영됩니다.
- 실측: 활성 채널 [telegram, slack] → 푸시 대상 [slack].

## 3. 반영 시점

두 기능은 실행기 코드에 들어가므로 **실행기 재시작 후** 적용됩니다. 지금 오늘 일상 글(작업 167)이 진행 중이라, 재시작하면 그 작업은 자동으로 이어받아 계속됩니다(어제 고친 이어가기 장치). 이번 재시작 시점에 시작 현황판 1장이 실제로 나갑니다.

## 4. 컨텍스트 분모 850K → 1M

`/autocompact`에 850k를 넣어 두신 상태입니다. 아래 한 줄을 채팅에 입력하면 기본값(1M 자동)으로 돌아갑니다.

```
/autocompact auto
```

(`/autocompact 1M`도 같은 효과입니다.)
