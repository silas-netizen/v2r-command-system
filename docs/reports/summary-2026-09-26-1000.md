# 핵심 요약 (09-26 10:00)

## 노출 확인 속도
- 지금 시간당 약 400건. 이론상 1,500건까지 가능한데 1/3만 나옴.
- 이유 1(고침): 글 확인 단계가 가끔 30초에서 129초씩 걸리는 꼬리 지연 → 대기 시간을 줄였다.
- 이유 2(추적 중): 작업자 6개가 동시에 2에서 3분씩 멈추는 현상. DB 경합인지 네이버 지연인지 계측으로 확정해 고치는 작업이 진행 중. 이게 풀리면 작업자 8개로 늘려 시간당 800건 이상을 노린다.
- 작업자를 그냥 8개로 늘리는 건 실측 결과 오히려 느려져(168건) 되돌렸다.

## 키워드 1만 개
- 어제 새 후보 45,000개 중 확정은 2.5%뿐이었음. 원인: 시드가 고갈된 상태에서 넓게 긁어 옴.
- 고친 것: 확정 키워드(0에서 2, 검색량순)만 시드로 우선 사용, 성과 낮은 출처 비중 자동 축소, 확정 키워드의 연관검색·자동완성 2단계 수집, 채점 적체 5,000 이상이면 수집 일시 정지, 거부 키워드 재수집 차단.
- 지금은 적체 채점이 먼저 풀려야 새 회차 효과가 나온다. 다음 보고에서 확정률 비교.
