  - 1-3. 재생성 방식: **A** API 절감판(캐싱+통합 호출, 25건 약 $1.4~2.1) / **B** GPT 웹 창(0원, 품질 시험 필요) / **C** 기존 시트 원고를 그대로 쓰고 생성기는 보조로만.
  - 1-4. 댓글 길이 규칙: 지금은 "상한 100% 초과만 실패"(댓글2 ≤70자, 나머지 ≤30자, 팥순이 ≤50자). 그대로 갈지, 상한 자체를 올릴지(기존 원고도 절반이 넘김).
  - 1-5. 기존 시트 원고에도 결함이 있음(키워드 2회뿐인 행 17편, 댓글2에서 브랜드 먼저 꺼내는 행, 팥순이 광고성 문장). 기존 원고를 그대로 발행할지, 생성기로 손볼지.
