## 3. 설계 (목표: 시간당 800~1,000건, 하루 2만 건 이상)

| 조치 | 효과 |
|---|---|
| ① 브라우저 상주 | 작업자마다 브라우저 1개를 켜 두고 페이지만 갈아 씀 → 건당 5~8초 절감 |
| ② 스크롤 조기 종료 | 카페 카드 영역이 로드되고 높이가 2번 연속 같으면 중단(보통 3~5번) → 건당 8~10초 절감 |
| ③ 후보 글 댓글 확인 최적화 | 대표 글만 열고(서브 링크 제외), 댓글2 계열만 읽음. 이미 확인한 글 URL은 하루 캐시 재사용 |
| ④ 병렬 작업자 | 브랜드별 전용 프로필(이미 있음: `browser-profile-naver-kw-<브랜드>`)로 **4~5개 작업자 동시 실행**, 사이드카 밖 별도 숨김 프로세스 |
| ⑤ 차단 방지 | 작업자별 간격 6~10초 무작위 + 미확인 연속 3건이면 그 작업자만 15분 휴식. 전체가 막히면 순환기가 30분 정지(기존 장치 유지) |
| ⑥ 우선순위 재검사 | 매번 5만 개를 다 도는 대신: 새 키워드·검색량 상위 → 노출완(밀려났는지 매일) → 밀려남(주 1~2회). 실제 필요한 하루 검사량을 1~2만 건으로 관리 |
