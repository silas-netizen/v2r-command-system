# "Codex용 장치 코드 인증" 스위치 위치 (2026-09-24 23:55)

지금 보신 화면은 **ChatGPT 앱**의 보안 메뉴라 이 항목이 없습니다. 이 스위치는 **웹(chatgpt.com) 설정**에만 있습니다.

## 휴대폰 브라우저에서
1. 브라우저(크롬·삼성인터넷)로 **https://chatgpt.com/#settings/Security** 접속(새 계정 clktrade07@gmail.com 으로 로그인 상태).
2. 보안 화면 맨 아래쪽 **"Codex용 장치 코드 인증"**(Device code authorization) 스위치를 켬.
   - 안 보이면 브라우저 메뉴에서 **"데스크톱 사이트 보기"** 를 켜고 같은 주소로 다시 → 보안 탭 하단에 나타납니다.
   - 그래도 없으면 화면의 **"고급 계정 보안"** 안을 확인.
3. 켠 뒤 "코드 다시"라고 보내 주세요 → 새 일회용 코드를 드리고, https://auth.openai.com/codex/device 에서 입력하면 끝입니다(앞서 드린 코드는 만료됨).

참고: 이 스위치는 새 계정에 한 번만 켜면 됩니다. PC 앞에 계실 때는 스위치 없이 PC에서 `codex login`(브라우저 자동 열림)으로도 가능합니다.
