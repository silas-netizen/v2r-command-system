# 슬랙 메시지 정책 재설계 + 자유 대화 명령 — 설계 (2026-09-23 17:45)

## 1. 슬랙으로 보내는 메시지는 4종류만

| 종류 | 언제 보내나 | 안 보내는 것 |
|---|---|---|
| 🔴 진짜 실패 | 발행이 끝나고 **자동 점검까지 거친 뒤에도** 실패로 남은 글이 있을 때 / 실행기가 죽고 자동 재시작도 실패 / 예약이 안 돌고 복구도 안 됨 / 로그인이 정말 풀림(백업·상주 크롬 확인까지 실패) / 요금제 한도로 생성 중단 / 계정 등록 제한 5건 이상. **사건당 1회 + 해결 시 ✅ 1회** | 되읽기 실패·미확정 같은 중간 상태, 자동 진단 문구, 재시도·"계속됨" 메시지 |
| 📊 정기 보고 | 09:00 일상 글 시작 현황판, 12·15·18시 중간 보고, 02:30 일일 보고 | 그 외 모든 정기·중간 알림 |

| 🟢 자유 대화 답변 | 아래 2번 | — |

텔레그램은 지금처럼 푸시 제외(명령은 받음).

## 2. 슬랙에서 채팅하듯 명령

- 정해진 명령 문법에 안 맞는 말은 **해석기(요금제 길, 0원)** 가 읽고 셋 중 하나로 처리합니다: ① 정확한 명령으로 바꿔 실행 ② 상태·질문에 답변 ③ 애매하면 되묻기.
- 예: "오늘 글 몇 개 나갔어?" → 답변 / "우아덤 원고 3개만 만들어 줘" → `우아덤 대량 원고 3건` 실행 / "발행 멈춰" → "지금 발행 중인 작업 167을 중지할까요? '네'라고 답하면 진행" → "네" → 중지.
- 위험한 것(중지·삭제·실제 발행)은 반드시 되묻고 "네"를 받은 뒤 실행합니다. 허용 명령 밖의 일은 만들지 않습니다.

## 참고: 이 채팅과 직접 대화

슬랙 해석기는 실행기 안의 별도 모델이 답합니다. 이 세션(저)과 직접 이어지는 대화는 Claude 앱의 원격 제어(Remote Control) 기능으로 휴대폰·다른 기기에서 가능하며, 원하시면 그 설정도 안내하겠습니다.
