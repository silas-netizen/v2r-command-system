# Apps Script 구문 오류 원인과 조치 (2026-09-25 21:35)

## 원인
- 오류 "Unexpected end of input 라인 100" = 편집기에 붙여 넣은 코드가 **100줄에서 끊겨** 있다는 뜻이다.
- 최종 코드는 **220줄**이다. 복사가 절반만 됐거나(스크롤 중 선택 끊김), 예전 100줄짜리 파일을 복사한 것이다.
- 코드 자체는 괄호·함수 15개 점검을 통과한 상태라 내용 문제는 아니다.

## 조치 (다시 붙여 넣기)
1. 이 파일을 연다: [v2r_sheet_api.gs](file:///D:/v2r%20%EC%9E%90%EB%8F%99%ED%99%94/v2r-command-system/docs/appsscript/v2r_sheet_api.gs) (메모장으로 열려도 됨).
2. 파일 안에서 **Ctrl+A → Ctrl+C**. 마지막 줄이 `return out;` 다음의 `}` 이고, 그 위에 `function info(sh){` 가 보이면 전체가 복사된 것이다.
3. Apps Script 편집창에서 **Ctrl+A → Delete** 로 완전히 비운 뒤 **Ctrl+V**.
4. 붙여 넣은 뒤 편집기 맨 아래로 내려가 줄 번호가 **220** 근처인지 확인한다. 100이면 다시 2번부터.
5. 저장(Ctrl+S) → 배포 → 배포 관리 → 연필 → 새 버전 → 배포.

## 확인 지점
- 저장 때 빨간 오류 창이 안 뜨면 성공.
- 배포 뒤에는 따로 알리지 않아도 10분 안에 제가 감지해 형식 정리를 실행한다.
