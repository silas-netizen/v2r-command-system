# 답변 (09-26 03:10) — 색 구분 상태

## 지금 상태
- 5개 시트 모두 **같은 색 규칙 13개**가 걸려 있다(03:00 적용 확인: 씨씨앙 연녹, 양평맘 연노랑, 쌍둥이맘 모여라 연주황, 러브인썸 연빨강, 마이웨딩드림 연청록 … / 노출완 초록, 밀려남·미확인 회색).
- 그런데 보이는 모양이 시트마다 다르다. 원인은 색이 아니라 **드롭다운 "표시 스타일"**이 시트마다 달라서다.
  - 칩 스타일(두 번째 사진): 값 옆 동그란 칩에 색이 들어감.
  - 화살표/일반 스타일(세 번째 사진, 코숨핏): 칩이 없어서 셀 배경 전체에 색이 칠해짐 → "배경색을 바꾼 것"처럼 보임.
- 표시 스타일은 시트 화면에서만 바꿀 수 있고 API로는 못 바꾼다(구글이 제공하지 않음). 그래서 아래 한 번만 부탁드린다.

## 통일 방법 (시트당 2번, 총 10번)
1. 시트에서 A열 머리글 클릭(열 전체 선택) → 메뉴 **데이터 → 데이터 확인**.
2. 오른쪽 패널에서 규칙 클릭 → 아래 **고급 옵션** 펼침 → **표시 스타일: 칩** 선택 → **완료**.
3. G열도 같은 방법.
4. 5개 시트 모두 반복.

## 그 뒤
- 칩 스타일이 되면 첫 번째 사진의 동그라미(현재 회색)에도 같은 색이 표시된다. 색 자체는 이미 통일돼 있어 더 손댈 것이 없다.
- 특정 색을 바꾸고 싶으면 값과 색만 말해 주면 5개 시트에 한 번에 다시 건다.
