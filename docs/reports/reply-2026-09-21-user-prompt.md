# 사용자 프롬프트가 이것뿐인 게 맞나 (2026-09-21 13:10 KST)

## 답: 맞습니다. 의도한 결과이고, 없어진 문장은 없습니다.
- 캡처의 사용자 텍스트("너는 내 다이어트 브랜드인 팥순이를 … 네이버 카페 작가야", "중요!!!! … 표현과 단어와 방식 독창적으로 … 한 사람이 쓴 것 같은 글 쓰지 마", "42.A 키워드에 맞는 제목…")는 **전부 시스템 프롬프트로 옮겨졌습니다.** 예: 팥순이 질문형 정리본 시스템 프롬프트 13행(역할 문장), 23행(독창성 절대 규칙), 제목·본문 규칙 절(키워드 제목).
- 사용자 프롬프트에는 **실행마다 바뀌는 값**만 남깁니다:
  ```
  작성 키워드: {{42.`0`}}
  키워드에 대한 현재 정보(참고용): {{74.choices[].message.content}}
  위 시스템 규칙대로 제목과 본문을 작성해줘.
  ```
  (모듈 2는 `{{83.textResponse}}` 본문 한 줄)

## 왜 이렇게 나누나
- 시스템 프롬프트 = "너는 누구고 어떤 규칙으로 쓰는가"(매번 같음). 사용자 프롬프트 = "이번엔 이 키워드로"(매번 다름). 이게 Anthropic이 권장하는 역할 구분이고, 같은 지침을 두 곳에 두면 모델이 어느 쪽을 우선할지 흔들려 원고가 들쭉날쭉해집니다(피드백에서 지적한 "맥락 틀어짐"의 원인 중 하나).
- 규칙이 시스템에 한 번만 있으면 강조 문장을 반복하지 않아도 같은 무게로 적용됩니다.

## 확인 방법
각 정리본 끝 "변경 로그"의 "옮김" 항목에 원래 사용자 텍스트에 있던 문장이 시스템 어느 절로 갔는지 적혀 있고, "빠진 규칙 0개" 확인 문장이 있습니다. Make에 반영할 때는 시스템 상자에 시스템 프롬프트 전체, 사용자 텍스트 상자에 위 3줄만 넣으면 됩니다.

## 겸사겸사
- 생성기 구현 완료(테스트 886 통과) + 정리본을 생성기 입력으로 연결 완료.
- 감시기에 숨어 있던 결함 1건 수정: 감시기가 남긴 "정체" 경고를 진행으로 세어 멈춘 작업을 영영 정리하지 않던 문제.
