# "로그인할 수 없음" 해결 방법 (2026-09-21 14:35 KST)

## 원인
구글은 **자동화 도구가 조종하는 브라우저**에서의 로그인을 거부합니다("브라우저 또는 앱이 안전하지 않을 수 있습니다"). 아까 창은 프로그램(Playwright)이 띄운 크롬이라 막힌 것입니다. 네이버는 이걸 안 막아서 됐던 것이고요.

## 바꾼 방법 (지금 적용됨)
- **로그인만은 진짜 크롬**을 우리 전용 프로필 폴더(`data/browser-profile-claude`)로 띄웁니다. 자동화 표식이 없어 구글이 막지 않습니다.
- 로그인 후 **그 크롬 창을 닫으면**, 프로그램이 같은 프로필을 보이지 않게 열어 로그인 여부를 확인하고 백업합니다. 이후 매일 09:20 점검·연장(Make도 동일, 하루 1회, 풀리면 텔레그램).

## 지금 하실 일
1. 방금 뜬 **새 크롬 창**(Claude 플랫폼 로그인 화면)에서 "Google 계정으로 계속하기" → 로그인.
2. 로그인이 끝나면 **그 크롬 창을 닫아 주세요**(닫아야 프로그램이 확인 단계로 넘어갑니다).
3. 끝나면 "됐어"라고 해 주시면 API 사용량을 읽어 정리하고, 이어서 Make 로그인 창도 같은 방식으로 띄웁니다.

## "구글 드라이브 접근 중이니 그걸로 보면 되지 않나"
- 드라이브 접근은 **드라이브 동기화 폴더(파일)** 를 읽는 것이지, 구글 계정으로 다른 사이트(Claude 플랫폼)에 로그인하는 권한이 아닙니다. 사이트 로그인은 그 사이트의 세션(쿠키)이 있어야 해서 위 방법이 필요합니다.
