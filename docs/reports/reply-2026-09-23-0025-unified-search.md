# 통검 판정 기준 반영 (2026-09-23 00:21 KST, 실측)

- 검색어: 자동완성 **첫 번째 항목**이 있으면 그 표기(띄어쓰기 포함)로, 없으면 띄어쓰기 규칙대로. 최종 검색어를 시트 I열(통합검색 URL)에 기록.
- 통검: 검색 결과 **첫 페이지 하나**를 **스크롤 끝까지** 내려 동적으로 붙는 영역까지 다 본 뒤 우리 글 유무 판정, 페이지 이동 없음. 순위(1~5순위 진입)는 그 최종 화면에서 위에서 몇 번째인지.
- 브라우저는 화면에 안 보이게 실행. 우아덤 30개로 재시험해 (원문→최종 검색어·상태·순위) 표를 드립니다. 규칙은 기억에 저장.
