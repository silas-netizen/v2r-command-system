# 모바일에서 세션 항상 보이게 · 원격 제어 안 끊기게 (2026-09-29 17:15)

## 방금 설정한 것 (PC 클로드 앱)
- 이 세션 **고정(Pin)** → 자동 보관 대상에서 빠지고 목록 맨 위에 항상 표시.
- 세션 자동 보관: **안 함(0일)** 상태 확인.
- 새 세션도 시작하면 **자동으로 원격 제어 연결**되게 설정.
- 세션이 일하는 동안 PC가 잠들지 않게 유지(이미 켜져 있음) + 이 세션은 추가로 깨어 있기 요청.
- 지금 상태: 원격 제어 켜짐, 실행 중, 보관 아님.

## 끊기는 원인은 하나 — PC가 잠들거나 클로드 앱이 꺼지면 끊김
원격 제어는 PC의 클로드 앱이 살아 있어야 이어집니다. 그래서 아래 2가지는 사용자가 직접 해야 합니다(시스템 설정은 제가 못 바꿉니다).

## 사용자가 할 일 (한 번만)
1. Windows **설정 → 시스템 → 전원** → "화면 및 절전"에서 **절전 모드 전환: 안 함**(전원 연결 시). 화면 끄기는 켜 두셔도 됩니다.
2. 클로드 앱을 종료하지 말고 **창 닫기(최소화)** 만. 앱 완전 종료·PC 재시작 뒤에는 앱을 다시 실행해야 모바일에서 보입니다.
3. 모바일에서 안 보이면: 폰 앱 재시작 → 코드 탭 → 목록 새로 고침 → "프로젝트 인수인계 문서" 열기.

## 추가 (17:20) — v2r 프로젝트 세션 전부 적용
- v2r 프로젝트(D:\v2r 자동화) 세션은 2개: **"프로젝트 인수인계 문서"(이 세션)** 와 **"작업 진행"**. 둘 다 원격 제어 켬 + 고정 완료. 보관된 세션은 없음.
- 다른 폴더의 세션("봇 탐지 회피 전략 연구", 임시 작업 공간)은 v2r 프로젝트가 아니라 건드리지 않음.
- 앞으로 새로 만드는 세션은 자동으로 원격 제어가 켜집니다.
