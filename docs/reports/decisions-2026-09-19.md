# 결정 사항 기록 (2026-09-19)

사용자 답변으로 확정된 규칙. 설계서와 설정에 반영한다.

| # | 항목 | 결정 | 반영 위치 |
|---|---|---|---|
| 1 | 사진 폴더 | **`브랜드/키워드` 폴더만 사용.** 없으면 새로 만들고 채운다. 브랜드 폴더 바로 아래 사진은 직접 쓰지 않고, 키워드 폴더를 채우는 원본 후보로만 쓴다(세탁본 생성). 원본이 하나도 없으면 텔레그램으로 "사진 필요" 알림 | `v2r/warehouse/store.py`, `config/brands.yaml` |
| 2 | 원본 일상 글 | 기존 시트 글은 딱딱해서 쓰지 않음. **제목 1줄 + 본문 1줄**의 짧은 일상 글을 새로 생성(모델: Sonnet 5, Make `☆일상 글 작성 모음☆` 지침 참고). 모든 카페용 풀 생성 | `v2r/warehouse/daily_collector.py`, `warehouse/manuscripts/daily_pool.jsonl` |
| 3 | `각색 전체` | 이미지가 아니라 **이미 수집해 둔 자사 카페 일상 글 엑셀**(A~F열). Drive의 `각색_전체_*.xlsx` 8개 + `각색_고요한아침_*(전체글 모음).xlsx` 2개를 내려받아 `warehouse/inbox/sheets/`에 등록. 일상 글 풀로 우선 사용 | `config/sources.yaml` (kind: xlsx_daily) |
| 4 | 실제 검증 | **모든 카페에 1건씩** 실제 발행하여 확인 (드라이런 → 실제) | 검증 단계 |
| 5 | 텔레그램 | 봇 `v260919_bot`, 채팅 ID 등록 완료, 확인 메시지 발송 | `.env` |
| 6 | 보고 형식 | **12줄 넘는 답변은 문서(MD)로 저장하고 채팅에는 3~5줄 요약 + 링크** | 운영 규칙 |
| 7 | 브랜드 시트 | (정정) `각색_…xlsx`는 브랜드 원고가 아님. 브랜드별 원고 시트는 아직 미확보 → 브랜드 글 발행 전 사용자에게 링크 요청 | `config/sources.yaml` |

## 텔레그램 처음 쓰는 분을 위한 확인 절차
1. 텔레그램 앱 → 상단 검색에 `v260919_bot` 입력 → 봇 선택.
2. 대화창 아래 "시작(Start)" 버튼 또는 아무 글자 입력 후 전송.
3. 봇이 "V2R 명령 시스템 연결 확인" 메시지를 보냈으면 성공. (이미 발송됨)
4. 앞으로 이 대화창에 "상태 알려줘" 같은 한국어 명령을 보내면 프로그램이 처리한다(실행기 `serve`가 켜져 있을 때).
5. 두 번째 휴대폰도 같은 텔레그램 계정이면 자동으로 됨. 다른 계정이면 그 계정으로 봇에 메시지를 보낸 뒤 알려주면 ID를 추가한다.

## 각색 xlsx 등록 방법 (사용자 작업 없음)
- Drive "일상 글 모음" 폴더의 `각색_전체_*.xlsx`, "완료"/"기관총 병합 파일" 폴더의 카페별 `각색_*.xlsx`를 Drive 데스크톱 동기화 폴더 또는 다운로드로 `warehouse/inbox/sheets/`에 두면 자동 등록. 다운로드는 사용자가 하거나, 브라우저로 내려받을 때 승인 필요.
