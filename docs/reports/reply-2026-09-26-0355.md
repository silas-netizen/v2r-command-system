# 답변 (09-26 03:55) — 팥순이 색이 사라진 원인과 복구

## 원인 (제 판단 착오)
- 구글 시트는 드롭다운 칩 색을 내부적으로 **조건부 서식 규칙**으로 저장한다. 03:40에 "제가 건 조건부 서식만 지운다"고 한 것이 실제로는 칩 색 자체를 지운 것이었다. 앞선 답변의 "칩 색은 규칙에 따로 붙어 있다"는 설명이 틀렸다.

## 복구 (03:52 완료)
- 5개 시트에 색 규칙 13개를 다시 걸었다. 팥순이 포함 모든 시트에서 칩 색이 다시 보인다(새로고침 필요할 수 있음).
- 색은 03:00에 통일한 그 색 그대로다(씨씨앙 연녹·양평맘 연노랑·쌍둥이맘 모여라 연주황 … / 노출완 초록·밀려남·미확인 회색).

## 두 사진 모양 차이의 진짜 원인
- 같은 규칙인데, **칩 스타일**인 열은 칩에만 색이 들어가고(두 번째 사진), **화살표 스타일**인 열은 셀 배경 전체에 색이 들어간다(첫 번째 사진, 코숨핏). 즉 색 문제가 아니라 열의 표시 스타일 차이다.
- 이건 API로 못 바꾸므로, 배경색처럼 보이는 시트(코숨핏 등)만 A열·G열 각각: 열 선택 → 데이터 → 데이터 확인 → 규칙 → 고급 옵션 → 표시 스타일 **칩** → 완료. 그러면 5개 시트가 두 번째 사진처럼 같아진다.
- 앞선 답변에서 부탁한 Apps Script 추가 배포(copy_validation)는 **필요 없다**. 취소한다.
