## A. 키워드 발굴 → 브랜드당 1만 개 (지시 1·3)
| 단계 | 내용 |
|---|---|
| A1 | 네이버 검색광고 **키워드 도구**(ads.naver.com 키워드 플래너)를 네이버 로그인 프로필로 자동 조회: 씨앗 키워드(시트 기존 키워드 + 브랜드 논리 낱말) → 연관 키워드 + 월간 검색량(PC·모바일) → 나온 키워드를 다시 씨앗으로 **꼬리 물기**(중복 제거, 브랜드당 1만 개 도달까지) |
| A2 | 보조 원천: 네이버 자동완성·연관검색어, 우리 색인 글 제목, 정리본 논리 낱말. 검색량은 반드시 키워드 도구 값 |
| A3 | 연관도 점수(0~3: 브랜드 논리와의 거리) 기록 → 멀수록 원고 프롬프트에 "이 키워드와 우리 논리의 당위성" 근거 문단을 필수로 넣는 규칙(N열 본문 분류·M열 비고에 표기) |
| A4 | 시트 두 번째 탭에 행 추가: H키워드·I통합검색 URL·K검색량·M비고·N분류 채움, G는 처음엔 `미확인` |
| 산출 | 브랜드별 `data/keywords/<브랜드>.csv` + 시트 반영, 일일 현황판에 "키워드 수·검색량 합" |

## B. 무한 반복 노출 확인 (지시 2)
| 단계 | 내용 |
|---|---|
| B1 | 판정 기준을 **통합검색**(통검)으로: 키워드 통검 결과(카페·블로그·VIEW 등 전체)에 우리 글(제휴·자사 카페 색인 + 브랜드 글) 있으면 `노출완`, 없으면 `밀려남`. 1~5순위 진입은 O열 |

- 지금은 시트를 **읽기만**(공개 CSV). 쓰려면 구글 Sheets API 동의가 1회 필요.
