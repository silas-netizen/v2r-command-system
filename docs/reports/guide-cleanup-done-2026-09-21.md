## 정리 방식(모든 브랜드 동일)
- 지침은 **전부 시스템 프롬프트**로: 역할 → [절대 규칙] 번호 목록(★·(중요) 대신) → 형식 → 내용 → 브랜드 정보 → 댓글 구조 → 예시 → 금지 목록.
- **사용자 프롬프트**는 Make 변수(키워드 `{{42.0}}`, 조사 결과 `{{74…}}`, 본문 `{{83.textResponse}}`)와 "위 시스템 규칙대로" 한 줄만.
- 같은 규칙 반복은 1개로 합침, 변수·자리표시(`{키워드}`·`{B/A}`·`{}`)·가상 멘트·예시문은 글자 그대로 보존. 각 파일 끝 "변경 로그"에 무엇을 옮기고 합쳤는지 기록.
- 다른 브랜드 문장이 복붙으로 남은 것(코숨핏에 "임신", 뉴더미스에 "코골이", 우아덤에 "항문", 코숨핏 "스무숨")은 정정하고 로그에 표시.
