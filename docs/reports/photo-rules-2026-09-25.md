# 사진 선택·세탁 규칙 정리 (2026-09-25 16:45) — 제 착오 정정 포함

## 정정
앞서 "키워드 폴더가 비어 있어 생성 승인 필요"라고 한 것은 제가 세탁본 폴더(washed)만 보고 판단한 착오입니다. 원본 폴더(originals)에는 사진이 있고, 규칙은 **생성이 아니라 원본 폴더에서 랜덤 선택 후 세탁**입니다. 생성 승인 요청은 철회합니다.

## 공통 규칙
1. 원본 위치: `warehouse/images/originals/<브랜드>/<폴더>/`. 본문 자리표시 `{키워드}` 하나당 사진 1장.
2. 선택: 해당 폴더에서 **랜덤**(팥순이 키워드 폴더만 파일명 일치). 이미 쓴 세탁본은 다시 쓰지 않음.
3. 세탁: 원본은 절대 첨부하지 않음 → EXIF 날짜·카메라 랜덤 변경 + 약한 그레인 + JPEG 92에서 95 → **가로 400px 이하**(비율 유지·확대 금지) → `warehouse/images/washed/` 에 저장 후 그 파일만 첨부.
4. 폴더가 비었으면 브랜드 루트·인박스 원본으로 키워드 폴더를 채워서 씀. 원본이 하나도 없을 때만 "사진 부족" 알림(생성은 승인 후).
5. 자리표시 위치: 팥순이 질문형 2번째 문단 뒤 `{키워드}`, 후기형 1번째 문단 뒤 `{키워드}`+`{B/A}`; 나머지 브랜드 2번째 문단 뒤 `{키워드}`. 태그 = 키워드 공백 제거 1개.
