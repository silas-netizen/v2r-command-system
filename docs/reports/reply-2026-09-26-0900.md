# 답변 (09-26 09:00) — Apps Script, 한 번 더 필요한가

- **예, 1회.** 이유: Apps Script는 "허용 시트 목록"에 있는 시트에만 쓰기 때문에, 새 갱년기 시트(1syyaWQz…)를 목록에 넣은 코드를 배포해야 갱년기 키워드를 그 시트에 붙일 수 있다. 지금 배포판에는 그 시트가 없다.
- 급하지 않다. 갱년기 키워드 수집·채점은 배포와 관계없이 지금 진행 중이고, 시트에 붙이는 단계는 확정 키워드가 어느 정도 쌓인 뒤(수천 개)다. **오늘 중 아무 때나** 하면 된다.
- 코드는 이미 갱신돼 있다: [코드 복사 페이지](file:///D:/v2r%20%EC%9E%90%EB%8F%99%ED%99%94/v2r-command-system/docs/appsscript/copy_v2r_sheet_api.html) → "코드 전체 복사" → Apps Script 편집창 Ctrl+A, Delete, Ctrl+V → 저장 → 배포 → 배포 관리 → 연필 → 새 버전 → 배포. URL이 바뀌면 보내 주면 반영한다.
- 앞으로 새 브랜드(시트)가 추가될 때마다 같은 1회 배포가 필요하다. 이것을 없애려면 스크립트가 "허용 목록" 대신 "같은 구글 계정의 모든 시트 중 탭 이름이 '노출 현황'인 것"을 허용하도록 바꿔야 하는데, 그러면 실수로 다른 시트를 건드릴 위험이 생겨 지금은 허용 목록 방식을 유지한다. 원하시면 바꾼다.
