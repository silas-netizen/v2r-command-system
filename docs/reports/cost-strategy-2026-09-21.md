## 추천: **B + C 혼합**
1. **기본은 C(요금제)**: 브랜드 원고 생성을 Claude Code 비대화 실행(`claude -p`, 구독 인증)으로 돌린다 → 추가 비용 0. 하루 25~50건 정도는 Max 요금제 한도 안에서 충분. 우리 검증기·부분 재시도·정리본 지침·예시는 그대로 감싼다(모델 호출부만 교체).
2. **한도에 걸리거나 급하면 B(배치 API)**로 자동 전환 → 건당 $0.08.
3. 즉시 필요한 소량(예: "지금 1건 만들어")만 A(일반 API).

## 주의 (솔직하게)
- C는 **이 채팅과 같은 한도**를 씁니다. 원고를 많이 뽑는 시간엔 제 작업 속도가 느려질 수 있어, 원고 생성은 새벽(02:00~08:00, 발행 정지 시간)에 몰아 돌리는 게 맞습니다.
- Anthropic 약관은 구독을 "자기 자신의 작업 자동화"에 쓰는 건 허용하지만, 상업 서비스의 백엔드로 대량 사용하는 건 API를 쓰라고 안내합니다. 우리는 내부 도구이므로 새벽 배치 수준이면 무리 없다고 보지만, 한도 경고가 오면 B로 넘기는 안전장치를 둡니다.
- 요금제 종류(Pro/Max 5x/Max 20x)에 따라 하루 처리량이 달라집니다. 어떤 요금제인지 알려 주시면 하루 가능 건수를 계산해 드립니다.
