# 클로드 업데이트 · 모델 바꾸는 법 (2026-09-27)

## 답
- 제가 아는 최신 모델은 **Opus 5 / Fable 5.1**입니다. "오푸스 5.5"는 제 정보엔 없어요. 모델 선택 목록에 안 보이면 아직 출시 전이거나 요금제에 안 열린 것이라 업데이트로 생기지 않습니다.

## 클로드 데스크톱 앱 업데이트
1. 앱을 완전히 종료 후 다시 실행 → 새 버전이 있으면 자동으로 받아 설치합니다.
2. 수동: 왼쪽 아래 프로필(또는 톱니바퀴) → **설정** → **정보/업데이트 확인**.
3. 모델 바꾸기: 채팅 입력창 근처 **모델 선택 메뉴**에서 고르면 됩니다(코드 탭도 같은 메뉴).

## 터미널용 클로드 코드(CLI) 업데이트
```bash
claude update
```
안 되면:
```bash
npm install -g @anthropic-ai/claude-code
```

## 사용자가 할 일
- 앱 재시작 후 모델 메뉴 확인. 원하는 모델이 목록에 있으면 선택, 없으면 아직 미출시.
