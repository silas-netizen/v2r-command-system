# 클로드 업데이트 방법 — Opus 5.5 쓰려면 (2026-09-27 16:05)

## 왜 설정에 업데이트가 없나
- 이 PC의 클로드 앱은 **Microsoft Store 버전**(설치 확인: Claude 2.2553.1.0, WindowsApps 폴더)입니다. 스토어 앱은 앱 안이 아니라 **스토어가 업데이트**하기 때문에 설정에 업데이트 메뉴가 없습니다.
- "이 컴퓨터에서 이 모델을 사용하도록 Claude를 업데이트하세요"는 앱 버전이 낮아서 Opus 5.5 가 잠긴 상태라는 뜻입니다.

## 할 일 (2분)
1. 시작 메뉴 → **Microsoft Store** 실행.
2. 왼쪽 아래 **라이브러리** 클릭 → 오른쪽 위 **업데이트 받기**.
3. Claude 업데이트가 끝나면 클로드 앱을 **완전히 종료 후 다시 실행**.
4. 모델 메뉴에서 **Opus 5.5** 선택.

## 그래도 안 되면
- 스토어 검색창에 "Claude" 입력 → 앱 페이지에서 **업데이트** 버튼.
- 그래도 회색이면 스토어 반영이 늦은 것이라 몇 시간 뒤 다시 시도.

## 사용자가 할 일
- 위 1에서 4 순서대로 진행.
