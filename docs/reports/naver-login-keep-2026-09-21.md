# 네이버 로그인 1회 → 자동 유지 (2026-09-21 10:30 KST)

## 지금 하실 일 (1회)
**방금 PC에 네이버 로그인 창(크롬)을 띄웠습니다.** 그 창에서 직접 로그인해 주세요.
- 로그인 화면의 **"로그인 상태 유지"를 꼭 체크**하세요(네이버가 세션을 길게 줍니다).
- 아이디·비밀번호는 프로그램이 입력하지도 저장하지도 않습니다. 2단계 인증이 뜨면 그것도 직접.
- 로그인되면 창에 "네이버 로그인 확인됨. 쿠키 N개 저장" 이 찍히고, 창을 닫으셔도 됩니다(15분 안에).
- 창을 놓쳤으면 PC에서 `scripts\naver-login.cmd` 더블클릭.

## 그 뒤로는 자동
| 무엇 | 어떻게 |
|---|---|
| 세션 저장 | 네이버 전용 브라우저 프로필 `data/browser-profile-naver` (다른 사이트 세션과 분리) |
| 매일 연장 | 매일 09:10 `네이버 세션 점검`: 보이지 않는 창으로 카페 홈을 한 번 방문 → 네이버가 세션을 연장. 긴 발행 중에도 실행됨 |
| web-crawler와 공유 | 점검·로그인 때마다 네이버 쿠키만 `data/naver_cookies.json`과 `web-crawler\output\cafe.naver.com\cookies.json`에 내보냄 → 수집 도구가 그대로 사용(다시 로그인 불필요) |
| 풀리면 | 텔레그램으로 "naver-login.cmd 실행해 주세요" 알림. 그때만 다시 1회 로그인 |
| 수동 점검 | 텔레그램에 `네이버 세션 점검` |

## 얼마나 유지되나
- "로그인 상태 유지" 체크 + 매일 방문이면 통상 수 주 이상. 네이버가 보안상 강제 로그아웃(비밀번호 변경, 새 기기 알림 등)하면 그때 알림이 옵니다.
- 실측 기록은 점검 결과의 `expires_in_days`로 매일 남깁니다.
