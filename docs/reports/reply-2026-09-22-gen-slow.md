## 오래 걸리는 원인 4가지
| 원인 | 설명 | 비중 |
|---|---|---|
| ① 요금제 길(CLI) 호출 | API 대신 `claude.exe`를 매번 새로 띄워 대답을 받음. 프로세스 시작·로그인 확인만 10~20초 | 중 |
| ② 프롬프트가 큼 | 지침 정리본 전문 + 골든 21개 + 시트 예시 = 호출당 입력 3.6만~6.1만 토큰. 호출마다 새로 읽음(캐시 재사용 0) | 큼 |
| ③ 출력이 김 | 본문 + 댓글 5개 + 대댓글 + 대대댓글2를 한 번에 → 호출당 출력 5천~7천 토큰(1분 이상) | 큼 |
| ④ 직렬 처리 | 6건을 한 줄로 하나씩. 검증 실패 조각은 부분 재요청(호출 +1) | 중 |

## 정리
- 1건 = 호출 2~3회 × 45~60초 ≈ 2분. **느린 게 아니라 정상 속도**이고, 0원(요금제)인 대신 API보다 1.5~2배 느립니다.
- 빠르게 하려면(원하시면 적용): 6건 동시 실행(6건 → 약 3분), 골든·정리본 캐시 재사용(입력 절반), 새벽 02:10 묶음 생성으로 미리 만들어 두기. 발행은 미리 만든 원고를 쓰므로 발행 속도엔 영향 없음.
