# 게시판·계정 배정 결함 수정 (2026-09-19)

태극 카페 첫 실제 발행 성공 직후, 나머지 9건이 **V2R에 글이 만들어지기 전에** 전부
실패했다. 원인은 두 가지였고 둘 다 계획(plan) 단계의 문제였다.

- **결함 1 (게시판)**: 명령이 카페를 지정하면(`spec.cafe`) 원고의 게시판을 무시하고
  전역 기본값 `자유게시판`으로 떨어졌다. 그런데 `자유게시판`은 태극·소나무에만 있다.
  → `'자유게시판'와(과) 일치하는 항목이 없습니다` 7건.
- **결함 2 (계정)**: 계정 시트 풀에서만 골라, 그 카페에 **가입하지 않은** 계정이 뽑혔다.
  (소나무 → `peecics`, 쌍둥이맘 → `byvzq427`)
  → `'…'에서 계정 …가 쓸 수 있는 게시판이 없습니다` 2건.

## 바뀐 것

### `config/cafes.yaml`
- `self_owned` 8개 카페와 `test` 2개 카페에 **`board`(기본 게시판)** 및
  **`board_aliases`(별칭)** 를 추가했다. 값은 `docs/reference/v2r-post-patterns.md`
  §2/§6의 활성화 단문 관찰 게시판 기준이고, 뚜렷한 값이 없는 곳은 실제 게시판 목록에서
  가장 일반적인 수다/자유 게시판을 골라 `# 추정`으로 표시했다.
- `test:` 값이 `이름: cafe_id`(정수)에서 `이름: {cafe_id, board}`로 바뀌었다.
  `reconcile._cafe_id_for`가 두 형태를 모두 받도록 했다(`sources/sheets.py`는 키만 쓰므로 영향 없음).

### `v2r/engine/publish.py`
- `cafe_matches()` — `catalog.match_name`과 같은 규칙(정규화 완전일치 → 한글만 일치 →
  부분 일치)으로 카페 이름 두 개가 같은 카페인지 판정. 이모지·공백·줄임말을 견딘다.
- `cafe_entries()` / `find_cafe_entry()` / `canonical_board()` / `cafe_default_board()` —
  제휴·자사·테스트 카페 설정을 한 모양으로 다루고, 게시판 별칭을 정식 이름으로 바꾼다.
- `prepare_manuscripts()` — `spec.cafe`가 있으면 **그 카페 원고를 먼저** 고르고,
  한 건도 없을 때만 다른 카페 원고로 되돌아간다(`CAFE_SCAN_LIMIT=500`행까지만 훑는다).
- `resolve_board()` — 새 우선순위:
  `spec.board` → (원고 카페가 해석된 카페와 맞을 때만) 원고 게시판 → 제휴 지정 게시판
  → **카페별 기본 게시판(`cafes.yaml`)** → 전역 기본.
- `writable_logins()` / `_cafe_members()` — `catalog.cafes` → `cafe_accounts`(force_drop /
  stop_member 제외) → `menus(...).writable_accounts`. 결과는 `rt.scratch`에 캐시해
  실행당 한 번만 조회한다(조회 범위도 자격 있는 계정으로 좁혀 호출 수를 줄였다).
- `_pool_for_cafe()` + `plan()` — 계정 그룹을 `work_type` 단독에서
  **`(work_type, 카페, 게시판)`** 으로 바꾸고, 기존 규칙(work_type·제외·매니저·제한·
  댓글 전용·LRU)을 적용하기 전에 풀을 위 권한 집합으로 좁힌다. 비면 카페·게시판을
  밝힌 한국어 오류를 낸다. 모의 실행에서 카탈로그가 캐시에 없으면 네트워크를 쓰지 않고
  시트 풀로 계획하되 계정을 `(실행 시 결정)`으로 표시한다.

`catalog.resolve`의 게시판 매칭은 이미 `normalize_name`(이모지·공백·기호 제거)과
부분 일치 규칙을 갖고 있어 그대로 두었다. 실측으로 10개 카페 모두 매칭됨을 확인했다.

## 확인

  게시판은 모두 해당 카페에 실재하는 이름으로 잡혔다(예: 웨딩 노트 `스냅 · 영상 후기`,
  송도포털 `랜선 집들이 · 거실 뷰`, 러브 인썸 `🌸신혼 일기장` — 원고 카페가 맞으면
  원고 게시판이, 아니면 위 표의 기본 게시판이 쓰인다).
