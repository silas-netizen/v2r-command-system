# 연관도 재채점 — 묶음 실패 원인과 조치 (2026-09-24 04:22)

## 발견
재채점 작업(181)이 돌고는 있지만 로그에 묶음 실패가 반복됩니다(채점 실패 25건, 묶음 포기 5건 = 키워드 500개 건너뜀).

| 실패 유형 | 예 | 원인 |
|---|---|---|
| 키워드 불일치 | 기대 "클랜징폼" ↔ 응답 "클렌징폼", "때타월" ↔ "때타올", "리포즘글루타치온" ↔ "리포솜글루타치온" | 모델이 오타를 교정해 돌려주면 100개 묶음 전체가 실패 처리 |
| JSON 잘림 | "모델 응답의 JSON이 끝나지 않았습니다" | 100개 + 당위성 논리 문장까지 내느라 응답 길이 한도 초과 |

실제 DB 기준 진행은 계속되고 있습니다(우아덤: 무관(4) 1,127 → 3,453, 당위성 논리 저장 203건).

## 조치 (일꾼 진행 중)
1. 응답 키워드를 **위치로 대응**하고 철자 차이가 작으면(편집 거리 30% 이하) 기대 키워드 그대로 받아들임 — 오타 교정으로 묶음이 통째로 버려지는 일 제거.
2. 묶음 100 → 50, 응답 길이 한도 4,000 → 8,000 — JSON 잘림 제거.
3. 포기된 묶음의 키워드는 다음 회차에 자동으로 다시 대상.
4. 커밋 후 실행기 재시작(재채점은 이어서 계속, 이미 채점된 것은 건너뜀).
