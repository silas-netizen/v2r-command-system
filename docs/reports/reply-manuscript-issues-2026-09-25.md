# 원고 지적 2건 — 원인과 해결 (2026-09-25 13:35)

## 1. "장어 → 장어즙" 논리 — 맞습니다, 이상합니다
- **원인**: 원고 생성 틀이 하나뿐입니다. 키워드를 늘 "겪는 문제·해 본 것"으로 놓고 브랜드를 "다른 해결책"으로 잇습니다. 키워드가 **브랜드 제품과 같은 원물·범주**(장어 ↔ 장으뜸 장어즙)일 때는 "해 봤는데 안 돼서 바꿨다"가 말이 안 됩니다.
- **해결(작업 중)**: 키워드 유형별 서사 틀 3종으로 분리 — (a) 같은 원물·제품 키워드 = "고르는 법·먹는 방식·차이 비교" 질문 틀(예: 장어를 어떻게 먹어야 흡수가 좋은지, 구이와 즙 차이, 원물 함량 기준) (b) 근접·확장 = 기존 "문제→관리법" 틀 (c) 당위성 = 저장된 논리 주입. 본문과 댓글2 계열 모두 적용.
- 추가 검증: 생성 후 "브랜드 연결이 상식적으로 자연스러운가"를 Opus 5에게 예/아니오로 물어 아니오면 재생성. 20건 전부 이 검증을 다시 돌려 걸리는 건은 재생성해 브랜드별 파일을 갱신합니다(장어 우선).

## 2. 줄 나눔 — 원고는 정상, 제가 만든 보기 파일의 문제
- 원고 본문에는 줄바꿈이 다 들어 있습니다(예: 장어 본문은 4개 문단·줄 단위). 제가 MD 파일에 본문을 그대로 넣어 마크다운이 한 줄 줄바꿈을 무시했습니다.
- **해결(완료)**: 브랜드별 4개 파일을 본문 코드 블록 형태로 다시 만들어 줄바꿈이 그대로 보이게 했습니다(방금 갱신). 발행 시에는 원고의 줄바꿈이 그대로 V2R에 실립니다(기존 발행분과 동일 경로).
