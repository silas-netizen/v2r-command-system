## 2. B(Apps Script 웹앱) 진행 방법 — PC에서 10분
코드는 준비해 두었습니다: [v2r_sheet_api.gs](file:///D:/v2r%20%EC%9E%90%EB%8F%99%ED%99%94/v2r-command-system/docs/appsscript/v2r_sheet_api.gs)
(허용 시트 5개·허용 작업 4개만, B에서 F열은 쓰기 금지, 비밀번호 열은 읽지도 않음, 새 행에 2행 서식·드롭다운 자동 복사, 동시 요청은 잠금으로 직렬화)

1. PC 브라우저에서 시트 소유 구글 계정으로 https://script.google.com → **새 프로젝트**.
2. 편집기의 기본 코드를 지우고 위 파일 내용을 그대로 붙여넣기 → 저장(프로젝트 이름 아무거나, 예: V2R 시트 API).
3. 오른쪽 위 **배포 → 새 배포 → 유형 선택(톱니) → 웹 앱**.
   - 설명: v2r
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** → 권한 승인 창이 뜨면 계정 선택 → "고급" → "이동" → 허용.
4. 나오는 **웹 앱 URL**(https://script.google.com/macros/s/…/exec)을 채팅에 붙여 주세요.

그 URL을 받으면 제가: 파이썬 쪽 쓰기 경로(러너 G·J·K·L 갱신, 키워드 추가, 삭제)를 전부 이 API로 바꾸고 → 5개 시트에서 소량 시험 → 브라우저 조작 경로는 읽기 전용으로만 남깁니다. 시트 접근 범위는 지금(링크 편집 가능)과 같아 추가 권한 노출은 없습니다.

참고: 휴대폰에서는 Apps Script 편집기가 열리지 않아 PC가 필요합니다. 그 사이 시트 복구는 스크립트로 계속 진행 중입니다.
