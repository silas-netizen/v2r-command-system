## 개선 (적용 중)
1. 모든 코딩 일꾼 프롬프트에 "한글은 Write/Edit 도구로만 쓸 것(Bash heredoc 금지)" 고정 문구.
2. 병렬 일꾼 간 인터페이스는 설계서에 함수 시그니처까지 적어 우회 코드를 줄인다.
3. 검증 일꾼은 한 번에 전체가 아니라 묶음별로 나눠 토큰을 분산한다.
4. 분석 일꾼은 Explore 타입, 범위는 파일 15개 이하로 제한한다.
5. 총 토큰 상한을 일꾼당 150k로 두고, 넘을 것 같으면 작업을 분할한다.
6. 브라우저 탭 하나를 쓰는 작업(Make 추출 등)은 병렬 금지. 폴더·묶음 단위로 순차 분할해 일꾼당 시나리오 5~7개 이하.
