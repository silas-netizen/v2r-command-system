# 브랜드별 1건 — 요금제 길로 다시 만들어 API 길과 대조 (2026-09-21)

요금제(구독) 길로 브랜드별 1건을 새로 만들고, 오늘 API로 만든 같은 키워드의 원고, 그리고 기존 완성 원고(시트 원문)와 나란히 놓았습니다.

- **요금제 길은 추가 비용이 0원입니다.** 이미 내고 있는 구독 안에서 처리됩니다.
- 모델에 넣은 지침(system)과 요청(user) 글자는 두 길이 완전히 같습니다. 아래 표의 `프롬프트 해시 일치`가 그 증거입니다.
- 키워드는 API판과 맞췄습니다(같은 입력이라야 대조가 됩니다).
- 오늘 API로 만든 원고 JSON에는 아직 지문이 안 적혀 있습니다(그 기능이 오늘 생겼습니다).
  그래서 **같은 브랜드·유형·키워드·카페·지침·예시로 프롬프트를 다시 만들어** 지문을 계산하고,
  요금제 길이 실제로 보낸 지문과 맞춰 봤습니다. 맞으면 두 길에 같은 글자가 들어간 것입니다.
- 발행하지 않았고 시트에도 쓰지 않았습니다.
