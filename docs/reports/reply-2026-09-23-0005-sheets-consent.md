# 시트 쓰기 연결 — 화면 1개만 직접 눌러 주세요 (2026-09-23 00:02 KST, 실측)

## 제가 한 것(구글 로그인 크롬 프로필)
- "링크만 있으면 편집 가능"이라도 프로그램이 시트에 **쓰려면** 구글 인증이 필요해서, 대신 **Apps Script 웹앱**(`V2R 시트 쓰기`)을 사용자 계정에 만들어 배포했습니다(코드 저장·배포 설정 "모든 사용자" 완료). 프로그램은 이 웹앱 주소로 시트에 행 추가·상태·P1/Q1 갱신을 합니다. 토큰·비밀번호를 다루지 않는 방식입니다.

## 남은 1가지(30초) — 구글 경고 화면은 보안 규칙상 제가 못 넘깁니다
크롬에 떠 있는 구글 창 **"Google hasn't verified this app"** 에서:
1. **Advanced** 클릭 → 아래 나타나는 **"Go to V2R 시트 쓰기 (unsafe)"** 클릭
2. 다음 화면에서 **허용(Allow)** 클릭(구글 스프레드시트 접근 권한 1개)
3. 창이 닫히고 Apps Script 화면에 "배포 완료 · 웹 앱 URL"이 뜨면 **"승인했어"**라고 해 주세요 → 제가 URL을 설정에 넣고 시트 쓰기 시험(우아덤 탭 P1/Q1 갱신)을 해서 결과 파일로 드립니다.
