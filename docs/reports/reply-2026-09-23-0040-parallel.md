# 5개 브랜드 병렬 실행으로 변경 (2026-09-23 00:33 KST, 실측)

- 방식: 네이버 로그인 프로필을 **브랜드별 복제본 5개**로 만들어(원본은 백업·보존, 재로그인 없음) 프로세스 5개가 동시에 키워드 도구를 조회. 복제본 하나가 로그인 풀림·차단 징후를 보이면 그것만 멈추고 나머지 계속(원본 프로필은 안 건드림). 첫 10분 이상 없으면 5개 유지, 문제 있으면 3개로 축소.
- 예상: 검증 통과(01:30) → 01:40 병렬 시작 → **브랜드당 1,000개 약 1시간 → 03:00 전후 5개 완료**(우아덤은 2,000개) → 03:30 실행기 재시작·노출 순환 시작.
- 진행은 30초마다 기록되며 아침 파일에 브랜드별 개수·검색량 합·상위 키워드를 넣습니다.

## 1만 개는 언제, 검증은 언제
- **검증 종료: 01:30** (잠금·헤드리스·충돌 시험·통검 30개 시험).
- **1만 개**: 키워드 도구는 조회 1회(씨앗 5개)에 연관어 수백~1,000개를 돌려줍니다(우아덤 첫 조회에서 710개). 브랜드당 1만 개 = 조회 약 30~60회(중복이 늘수록 더 필요) ≈ 20초/회 → **1~2시간**. 병렬 5개이므로 **오늘 03:30~04:30 사이에 브랜드별 1만 개 도달 예상**. 단, 연관어가 바닥나 중복만 나오는 브랜드(예: 코숨핏 코골이·비염 좁은 주제)는 1만 개까지 씨앗을 더 넓혀야 해 하루 더 걸릴 수 있습니다 — 그 경우 아침 파일에 도달 개수와 남은 계획을 적습니다.
- 목표를 바로 1만 개로 올려 두었습니다(1,000개에서 멈추지 않음).
