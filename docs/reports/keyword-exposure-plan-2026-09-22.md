## 2. 만들 것(제안 → 바로 구현 시작)
| 단계 | 내용 | 도구 |
|---|---|---|
| ① 노출 검사 | 브랜드별 키워드 전부(시트 `노출 현황` 탭의 키워드 + 우리가 발행한 브랜드 글의 키워드)를 **네이버 검색 카페탭**에서 조회 → 우리 글 URL이 상위 N(기본 10)에 있으면 노출, 없으면 밀려남, 글 자체가 없으면 미발행 | insane-search/web-crawler(네이버 로그인 세션 유지) 또는 네이버 검색 결과 페이지 직접 조회. 하루 1회(08:00) + 브랜드 글 발행 다음날 재검사 |
| ② 저장 | DB 표 `keyword_exposure(brand, keyword, cafe, article_url, rank, status, checked_at)` 이력 누적. V2R의 T0 결과도 함께 저장 | SQLite |
| ③ 보고 | 현황판에 "브랜드 키워드 노출" 섹션: 브랜드별 노출/밀려남/미확인 수 + 이번에 새로 밀려난 키워드 목록. 일일·중간 보고 모두 | 새 현황판 |

| ⑤ 명령 | `키워드 노출 현황` / `우아덤 노출 현황` 한국어 명령 추가 | 파서 |
