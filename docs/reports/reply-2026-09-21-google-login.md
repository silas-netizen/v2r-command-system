# "구글 로그인 왜 풀렸어" 답변 (2026-09-21 13:45 KST)

## 풀린 게 아닙니다
- 지금 보이는 Make 로그인 화면은 **이 앱 안에 내장된 별도 브라우저**입니다. 크롬과 세션을 공유하지 않아서 원래부터 아무 계정에도 로그인돼 있지 않습니다. 사용자의 **크롬 구글 로그인은 그대로**이고, 제가 건드린 적도 없습니다.
- 제가 "무조건 유지"를 약속한 건 **네이버**(와 ChatGPT) 세션입니다. 방금 다시 점검: **네이버 로그인 OK, 남은 30일, 백업 정상, 경고 없음.**

## 왜 크롬으로 안 봤나
- 크롬을 쓰려면 "Claude in Chrome" 확장이 이 앱과 연결돼 있어야 하는데, 지금 연결이 응답하지 않습니다(확장이 꺼져 있거나 로그인 안 됨). 그래서 대안으로 내장 브라우저에 Make 로그인 화면을 열어 둔 것입니다.

## 선택
1. 내장 브라우저에서 "Continue with Google" 한 번 로그인(이 브라우저에도 세션이 남아 다음엔 안 물어봄) → 제가 Make 사용량을 바로 정리.
2. 크롬 우측 Claude 패널을 열어 이 앱과 같은 계정으로 로그인해 확장을 연결 → 크롬의 기존 구글 세션으로 봄.

둘 다 비밀번호는 사용자가 직접 입력하고, 제가 저장·입력하지 않습니다.
