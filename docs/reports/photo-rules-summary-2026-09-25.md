## 1. 모든 브랜드 공통 흐름

1. 원고 본문의 `{키워드}` 같은 자리표시자 1개당 사진 1장을 넣는다. 사진을 못 찾으면 그 글은 등록하지 않는다.
2. 사진은 **생성이 아니라 창고 원본 폴더에서 고른다.** 경로는 `warehouse/images/originals/<브랜드>/<폴더>/`.
3. 폴더 안에서 **랜덤 1장**을 고른다(팥순이 `{키워드}`만 파일명 일치 방식).
4. **같은 실행(한 번의 발행 묶음) 안에서 같은 원본을 다시 고르지 않는다.** (09-25 수정, 커밋 f9ac7df)
5. 고른 원본을 **세탁**해 세탁본만 첨부한다. 원본 직접 첨부는 금지. 첨부 경로는 항상 `warehouse/images/washed/<원본 해시>/<번호>.jpg`.
6. 사진 폴더는 **지금 있는 것으로 고정**(새 폴더 없음). 폴더가 비었거나 부족할 때만 생성하며, 생성 전 승인을 받는다. 장으뜸은 생성 자체 금지.

## 2. 세탁(워시) 규칙

| 항목 | 내용 |

| 촬영 정보 | 카메라 제조사·모델·렌즈·ISO·조리개·노출·초점거리를 미리 정한 실제 기기 묶음(아이폰·갤럭시·소니 등) 중 하나로 랜덤 교체 |
| 촬영 날짜 | 최근 며칠 안의 임의 날짜·시각으로 교체(DateTime·Original·Digitized 모두 같은 값) |
| 그 외 메타 | GPS 등 나머지 태그는 원본 그대로 보존 |
| 픽셀 변경 | 가장자리 1px 잘라내기(상하좌우 중 랜덤 한 쪽) |
| 크기 | 가로 400px 초과 시 비율 유지 축소. **확대는 절대 안 함**, 400px 이하면 그대로 |
| 저장 | JPEG 품질 92에서 96 랜덤, 서브샘플링 없음. 회전·블러·강한 노이즈 등 화질 저하 후처리 금지 |
| 세탁본 수 | 원본 1장당 최소 1개 세탁본, 발행 때 아직 안 쓴 세탁본을 골라 씀 |

## 4. 코숨핏 주제 라우팅

- 키워드(공백 제거·대소문자 무시)에 **비염·축농증·코막힘·알레르기·항히스타민·이비인후과**가 들어가면 → 비염 폴더.
- **코골이·양압기·수면무호흡·입호흡·무호흡**이 들어가면 → 코골이 폴더.
- 둘 다 안 걸리면 기본 규칙(키워드 폴더 31장, 사용자 실사진).
- **영구 제외 폴더**: 기사·자료·삽화 계열(대체제_기사_자료, 비염 괴로움_이미지, 코골이_개선이유_기사_자료, 스무숨_착용사진, 수면점수 등 구 인박스 폴더). 의학 삽화·방송 캡처라 발행 사진으로 부적합.
- 비염·코골이 폴더는 사용자가 준 구글 드라이브 링크에서 적재한 15장씩이며, 이것으로 고정.

## 5. 금지·주의 사항

- 세탁 안 된 원본 첨부 금지, 400px 초과 첨부 금지.
- 세탁본(washed) 폴더가 비어 있다는 이유로 "생성 승인 필요"로 판단하지 않는다. 원본 폴더에 사진이 있으면 그 자리에서 세탁해 쓴다.
- 새 사진 생성이 필요하면 ChatGPT 요금제 웹으로만, 인위적 AI 느낌 금지, 음식·제품 클로즈업, 연출 소품·사람 구도 금지. 생성 전 승인 요청 → 결과 승인 후에만 세탁·적재.
- 태그는 키워드에서 공백을 뺀 1개만.
