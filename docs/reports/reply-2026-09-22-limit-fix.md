| 글로시 마이 | 09-22 09:03 | 성공, 검색 노출 |
| 송도포털 | 09-22 09:08 | 성공 |
| 마이 웨딩 드림 | 09-22 09:00 | 성공 |

- 어제 본 경고 아이콘은 "잠시 제한" 상태였고 V2R이 오늘 자체 재시도로 올렸습니다. 그래서 우리 DB의 성공 표시는 결과적으로 맞았지만 **판정 근거가 틀렸던 것**이라 로직을 고쳤습니다. 재발행은 하지 않았습니다(하면 중복 글). 부수 효과: 이 4건이 오늘 peecics 몫 4건을 씀.

## 고친 것(다음 재시작부터)
- 제한 판정은 화면 경고 문구와 같은 API 필드(`fail_reason`)로. '준비' 상태만으로는 구분 불가(정상 예약도 '준비').
- 제한 글은 성공이 아니라 **실패(제한)**로 기록 + 같은 행 재발행 대기 줄(자동 실행 안 함, 현재 0건).
- 계정 하루 상한 100건, 제한 응답 오면 그 계정 당일 제외 + 다른 계정으로 1회 재시도.
- 현황판·일일 보고에 "제한 걸린 글" 카드·열.
- 테스트 1,120 통과, GitHub 반영. 실행기 재시작은 발행 사이(오늘 묶음 끝난 뒤)에 제가 합니다.
