# Claude API 사용량 확인 — 크롬 연결 상태와 대안 (2026-09-21 14:00 KST)

## 크롬으로 하려 했지만
- 크롬 확장(Claude in Chrome)이 이 앱과 **연결돼 있지 않아** 두 번 시도 모두 응답이 없습니다. 이건 제가 켤 수 없습니다.
- 연결하려면: 크롬에서 확장 설치(https://chromewebstore.google.com/detail/fcoeoabgfenejglbffodgkkbkcdhcgfn) → 크롬 우측 Claude 패널 열고 **이 앱과 같은 계정으로 로그인**. 그 뒤 "크롬 연결했어"라고 하시면 크롬의 구글 세션으로 바로 봅니다.

## 지금 당장 볼 수 있는 방법(더 빠름)
- 앱 안 브라우저에 **Claude 플랫폼 사용량 페이지**(platform.claude.com → Usage)를 열어 두었습니다. 화면의 **"Google 계정으로 계속하기"** 한 번만 눌러 로그인하면(같은 구글 계정), 제가 바로 읽습니다.
- 정리할 항목: 이번 달 총 비용, 일별 비용 추이, 모델별(Opus/Sonnet/Haiku) 토큰·비용, **API 키별**(Make 시나리오용 키 vs 우리 시스템 키) 사용량, 캐시 읽기 비율. Make 쪽은 말씀대로 작업(operations) 소모량만이라 참고로만 봅니다.
