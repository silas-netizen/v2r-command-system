# 재부팅 — 압축 후 맥락 복원

`/컴팩트` 로 저장한 `docs/session-state/latest.md` 를 기준으로 맥락을 되살린다. **요약을 믿지 말고 파일과 실제 상태를 다시 본다.**

## 해야 할 일 (순서대로)

1. `docs/session-state/latest.md` 전체를 읽는다. 없으면 `docs/session-state/` 의 가장 최근 파일.
2. 메모리 인덱스 `C:\Users\user\.claude\projects\D--v2r----\memory\MEMORY.md` 와, latest.md 가 가리키는 메모리 파일들을 읽어 절대 규칙을 다시 적용한다.
3. latest.md 의 "진행 중" 항목을 **실제로 검증**한다:
   - 실행기: `logs/serve.log` 꼬리, `data/v2r.sqlite` 의 `jobs` 에서 running/queued 작업, 심장박동 시각.
   - 백그라운드 일꾼/프로세스: 출력 파일이 있으면 꼬리를 읽어 끝났는지 확인.
   - 세션 크론: 목록을 확인하고 없어진 것은 다시 만든다.
   - 오늘 발행 건수 등 숫자 현황을 `date` 실측 시각과 함께 다시 센다.
4. latest.md 의 "미결·대기 사항"과 "다음에 할 일"을 그대로 이어서 진행한다. 사용자에게 다시 묻지 않는다(이미 정해진 것은 재확인 금지).
5. 복원 결과를 `docs/reports/reboot-YYYY-MM-DD-HHMM.md` 로 남긴다: 무엇을 읽었고, 실제 상태가 저장 내용과 어디가 달라졌는지, 지금부터 이어갈 일 순서.
6. 채팅에는 **그 파일의 file:/// 절대 링크 + 한국어 한 문장**만 낸다(절대 규칙).

## 금지

- "요약을 보니…", "이어서 하겠습니다" 같은 진행 문장·영어 출력 금지.
- 저장 내용과 실제가 다르면 실제를 우선하고 차이를 보고서에 적는다.
- 자격 정보는 어디에도 다시 적지 않는다.
