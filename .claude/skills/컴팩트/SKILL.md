# 컴팩트 — 압축 전 맥락 저장

사용자가 컨텍스트를 압축하기 직전에 부른다. 압축으로 잊혀질 내용을 **파일에 전부 남기는** 것이 목적이다.

## 해야 할 일 (순서대로)

1. `date` 로 현재 시각을 실측한다.
2. 아래 항목을 **빠짐없이** 적어 `docs/session-state/latest.md` 에 저장한다(덮어쓰기). 같은 내용을 `docs/session-state/YYYY-MM-DD-HHMM.md` 로도 남긴다.
3. 저장 후 채팅에는 **저장 파일의 file:/// 절대 링크 + 한국어 한 문장**만 낸다(절대 규칙). 그 다음 사용자가 `/compact` 를 실행한다.

## latest.md 에 반드시 들어갈 항목

- **세션 개요**: 저장 시각, 현재 하던 일 한 줄, 직전 사용자 메시지 원문(가장 최근 5개는 그대로 인용).
- **절대 규칙 요약**: 채팅 형식(파일 링크+한 문장, 진행 문장·영어 금지, 알림에는 무응답), 창 띄우기 금지, 로그인 유지·자격 정보 미취급, 시트 권한 질문 금지, 파일 언급은 file:/// 절대 링크, 알림 등급/아이콘, 텔레 푸시 중지·슬랙만 등 **이 세션에서 새로 생긴 규칙 전부**.
- **이번 세션에서 내린 결정**: 날짜·시각과 함께, 왜 그렇게 정했는지 한 줄씩.
- **완료한 작업**: 커밋 해시와 한 줄 설명, 만든 보고서 파일 링크(file:///).
- **진행 중인 것**: 실행기 상태(pid·재시작 시각), 돌고 있는 작업 번호·상태, 백그라운드 일꾼/프로세스(작업 id, 무엇을 하는지, 출력 파일 경로), 세션 크론(시각·내용), 예약 일정 변경.
- **미결·대기 사항**: 사용자 답을 기다리는 것, 다음에 할 일 순서, 알려진 문제와 임시 조치.
- **핵심 파일·경로**: 이 세션에서 만지거나 자주 참조한 파일 경로(file:///), 시트 ID, 채널 ID, 스크립트.
- **숫자 현황**: 오늘 발행 건수, 키워드/연관도/노출 진행률 등 마지막으로 확인한 값과 그 시각.
- **주의할 함정**: 이번에 겪은 사고와 원인(예: 시트 필터→gviz 잘림, AppData 가상화, CRLF, 임대 15분).

## 형식 규칙

- 한국어, 파일 언급은 전부 `file:///D:/v2r%20%EC%9E%90%EB%8F%99%ED%99%94/...` 절대 링크(백틱 파일명 금지).
- 요약하지 말고 **재부팅 후 그대로 이어서 일할 수 있을 만큼** 구체적으로. 길어도 된다.
- 자격 정보(비밀번호·키 종류)는 절대 적지 않는다.
- 저장 전에 메모리 폴더(`C:\Users\user\.claude\projects\D--v2r----\memory\`)에 새로 생긴 규칙이 있으면 메모리 파일도 갱신한다.
