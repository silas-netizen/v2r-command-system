# 공통 작성 규칙 요약 (12개 시나리오 교차 분석)

## 1. 파이프라인 공통 골격

카페 바이럴 시나리오 6개(우아덤/장으뜸/코숨핏/뉴더미스/팥순이 질문형·후기형)는 동일한 골격을 씁니다.

```
Google Sheets: getSheetContent (A2:G, 헤더 없음, select=list)
  -> Perplexity sonar (search_domain_filter = naver.com, max_tokens 500, temp 0.6)
  -> BasicRouter
  -> Claude #1 : 제목 + 본문 생성   (claude-opus-4-5-20251101, effort high)
  -> Claude #2 : 댓글 + 대댓글 생성 (claude-opus-5, effort high, max_tokens 1000~2000)
  -> Google Sheets: updateCell (B열 = 본문 + 개행 3~4개 + 댓글)
```

- 시트 셀 주소는 항상 `{{join(add(emptyarray; "B" + 42.`__ROW_NUMBER__`); "")}}` 형태.
- 일상글 시나리오(폴더 ☆일상 글 작성 모음☆)는 Perplexity/댓글 단계가 없고, 스프레드시트 하나를 시트 탭으로 구분해 C열(또는 B열)에 저장.
- 입력 키워드는 바이럴 계열 A열 = `{{42.`0`}}`, 일상글 계열은 `{{42.`0`}}` = 번호 / `{{42.`1`}}` = 키워드.

## 2. 톤 & "AI 티 제거" 규칙 (거의 모든 프롬프트에 그대로 반복)

- "실제 카페 회원이 쓴 것처럼" 보이는 것이 최우선. AI가 쓴 티가 나면 실패.
- **쉼표(,)와 마침표(.), `...` / `..` 말줄임표 전면 금지.** 물음표(?), 느낌표(!), 물결(~)만 허용.
- 문장 구분은 `ㅋㅋ / ㅠㅠ / ㅎㅎ` 로 대체하고, 개수를 불규칙하게 섞음(ㅋㅋ, ㅋㅋㅋㅋ).
- 띄어쓰기를 의도적으로 2~3개 틀리기.
- 맞춤법을 흔히 틀리는 수준으로 한 글에 1~2개만 틀리기: 에요/예요 혼용, 안돼요→안되요, 맞아욬ㅋㅋ, 되/돼, 웬/왠, 할수있어.
- 이모지(그림 이모지) 금지, 한글 이모티콘만 사용.
- 나열식·정리식·마크다운(`*`, `**`, `>`, `---`) 출력 전면 금지.
- 페르소나는 매 키워드마다 독창적으로 다르게. 같은 시작 문구/패턴 반복 금지(연속 3회 이상 동일 패턴 금지).

## 3. 제목 규칙

- 공백 포함 **30자 이내**, 1문장.
- 바이럴 계열: 제목 시작을 작성 키워드로, 물음형 + 우는 이모티콘(ㅠㅠ) 조합으로 클릭률 유도.
- 일상글 계열: 행 번호를 3으로 나눈 나머지로 형식 배정 — 나머지 1=물음형, 2=명사 조합형, 0=평서형.
- 팥순이 후기형: 제목에 브랜드명("팥순이") 언급 금지, "이거", "이것만" 등 대명사로 대체.
- 출력에 `*` 표시 금지.

## 4. 본문 분량·가독성

| 유형 | 분량(공백 제외) |
|---|---|
| 카페 바이럴 본문 (우아덤/뉴더미스/코숨핏/장으뜸) | 최대 250자 |
| 팥순이 질문형 | 200자 내외 |
| 팥순이 후기형 | 300자 내외 |
| 정보성(키워드 포함) | 200~300자 |
| 일상 글(소재 포함) | 20~30자 또는 20~40자 |
| 자유게시판(Gemini) | 20~80자 |

- 모바일 기준: **1줄 20자 이내**, **1문단 4줄 이내**, 문단 나눔 많이.
- 같은 문단 안에서는 빈 줄(엔터) 넣지 말 것 — 문단 사이에서만 빈 줄.
- 분량 맞추려고 중간에 글을 끊지 말고 반드시 끝맺음할 것.
- 키워드 포함 횟수: 바이럴 본문 3회, 일상글 1회, 팥순이 후기형 3~4회. A열 키워드는 한 글자도 빼먹지 말 것.

## 5. 본문 구조

- 바이럴 4종 공통: **오프닝(공감·페르소나) → 솔루션(문제 발생 과정 + 과거 노력 실패 + 현재 고민) → 클로징(조언 요청 질문)**. 마지막은 반드시 "해결 방법을 알려달라"는 조언 요청으로 마무리해, 제품 언급이 댓글에서 자연스럽게 나오도록 유도.
- 팥순이 질문형: 4단계 — 고민 상황(50자) → 키워드 접한 계기(50자) → 핵심 궁금증(50~60자) → 후기 요청(40~50자).
- 팥순이 후기형: 키워드 단독 사용 → 아쉬운 점 → 팥순추출물 다이어트 발견 → 병행 효과 → 추천. 시작/마무리 패턴 각 5~6종 로테이션 규정.
- 일상글: `제목 :` / `본문 :` 2블록 고정 출력.

## 6. `{ }` 이미지 placeholder 생성 규칙

- **중괄호는 반드시 문장 단독으로**, 앞뒤 줄 나눔 필수.
- 바이럴 4종(우아덤·장으뜸·코숨핏·뉴더미스) 및 팥순이 질문형: 본문 **두 번째 문단이 끝난 뒤** `{키워드}` 표기. 이때 `{키워드}`는 A열 값이 아니라 **텍스트 그대로 "키워드"**.
- 팥순이 후기형: 본문 **첫 번째 문단 뒤** `{키워드}`, **병행 효과 부분**에 `{B/A}` (비포/애프터 이미지).
- 구버전 1214057(OpenAI)만 중괄호가 아니라 소괄호 `(착색된 겨드랑이 사진)` 형식으로 이미지 3장을 지정.

## 7. 댓글/대댓글 생성 규칙 (Claude #2)

### 출력 포맷 (모든 바이럴 시나리오 동일, 총 12개)
```
댓글1: / 대댓글1:
댓글2: / 대댓글2: / 대대댓글2: / 대대대댓글2:
댓글3: / 대댓글3:
댓글4: / 대댓글4:
댓글5: / 대댓글5:
```
- 1세트만 출력. "댓글 세트 1", 이모지 머리표, `---`, `*`/`**` 등 부가 코멘트·구분 기호 출력 금지.
- 글자 수: 댓글2를 제외한 모든 댓글 **30자 이내**, 댓글2는 **70자 이내**(공백 제외 100자 초과 금지). 팥순이 계열은 전 댓글 50자 이내.
- 줄 나눔 없이 한 줄로.

### 2번 세트 = 퍼널의 핵심 (4단 구조)
1. **댓글2** — 권위재(의사/수면클리닉/논문/카페 추천)를 근거로 "원씽 이동" 제시. 제품명은 아직 언급 금지, 작동 원리(흡수율 / 기도근육 강화 / 항문 보호막 강화 / 팥순추출물)만 강조. 작성 키워드를 생략 없이 포함.
2. **대댓글2 (작성자)** — 처음 듣는 듯 궁금증 질문. 제품이 아닌 "성분/방법"으로 질문.
3. **대대댓글2** — 제품명 최초 언급 + 프레임 분리(경쟁 대안은 효과 없음) + "검색해보면 나올 거예요" 유도. 70자 이내.
4. **대대대댓글2 (제3자)** — "222 저도 효과 봤어요" 식 여론 형성.

### 나머지 댓글 역할
- 댓글1: 제품과 무관한 중립적·객관적 정보 답변 → 광고성 없음을 증명. 대댓글1은 작성자가 **처음 알게 된 듯한 반응**만 (정보 공유형 답변 금지).
- 댓글3: 비슷한 고민 경험 공유(제품 무관). 대댓글3은 맞장구.
- 댓글4: 작성자가 시도한 잘못된 방법을 부드럽게 지적 / 가벼운 톤 유지 (2문장 내외).
- 댓글5: 제3자 여론 보강. **수치·기간을 구체적으로**. 다른 제품 언급 금지. 대댓글5는 호기심 반응.

| 장으뜸 장어즙 | 대댓글2에서 "제품"이라는 단어 금지, 대대대댓글2는 장으뜸 언급 금지 |
